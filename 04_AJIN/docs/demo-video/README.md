# AJIN 웹 시연 영상 — 프롬프트 패키지 (README / 인덱스)

레퍼런스 **`UIUX모션작업 포트폴리오_어플시연영상 COZY`** (YouTube `1ddZ_eaNwmw`, ≈1:46, 음악 only UI/UX 모션 쇼릴)
의 **포맷**을 학습해, **AJIN 규제·컴플라이언스 모니터링 웹앱**의 시연 쇼릴로 재구성한 **씬별 프롬프트 모음**.

- 이미지 생성: **GPT IMAGE 2.0** (각 씬 히어로 스틸)
- 영상 생성: **Google Omni** (스틸 → image-to-video 애니메이션)

## 확정 파라미터
| 항목 | 값 |
|---|---|
| 화면비 | **16:9 데스크톱** (1792×1024 → 1920×1080) |
| 길이 / 씬 수 | **≈90초 · 10씬** (씬당 8~10초) |
| 오디오 | **음악 only + 한글 온스크린 키네틱 타이포** (내레이션 없음, 레퍼런스와 동일) |
| 강조 기능 | **실시간 알람(D 컴플라이언스 + F 설비 SPC)** · **승인 워크플로우 + 협력사 + 학습(LMS)** |
| 톤 | 다크 글래스 "규제 관제탑", 프리미엄·시네마틱·데이터 드리븐 |

## 제작 워크플로우 (병렬)
1. **(준비)** `00_STYLE_GUIDE.md` 숙지 → 공통 [AJIN VISUAL DNA] 블록 확보
2. **(이미지 · 병렬 10개)** 각 `scene_NN`의 *GPT IMAGE 2.0 프롬프트* → 스틸 10장 생성 (씬 독립 → 동시 진행 가능)
3. **(영상 · 병렬 10개)** 각 스틸 + *Google Omni 프롬프트* → 클립 10개 (image-to-video)
4. **(편집)** 비트 컷 + 한글 키네틱 타이포 오버레이 + 트랜지션 + 믹스
5. **(UI 정확도)** 텍스트 촘촘한 씬(03~09)은 실제 앱 스크린샷/AE 타이포 오버레이 권장(§9)

## 사용 팁
- 각 씬 파일은 **독립 실행 가능**(프롬프트 자체에 DNA 블록 포함). 순서 무관하게 병렬 생성.
- 실제 데이터 예시(EU REACH 6가 크롬, UFLPA, KORUS FTA, 산안법 프레스 안전거리 등)를 알람 카드 카피로 사용 → 진정성↑.
- 길이·카피·색은 자유 조정. 변경 시 `00_STYLE_GUIDE.md`의 토큰을 기준으로 유지.
