# AJIN 시연 스크립트 (제3회 실리 경진대회)

> **목적**: 시연 중 입력값/타이밍/순서를 고정하여 시연 실패 리스크를 최소화하고, 신청서가 약속한 정량 KPI를 한 화면 안에서 입증한다.
>
> **소요 시간**: 5개 시나리오 × 약 2분 = **총 10분**
> **사전 준비**: 본 스크립트 §0 워밍업 명령을 시연 5분 전 1회 실행

## 0. 사전 워밍업 (시연 5분 전, 필수)

Cloud Run 콜드스타트 회피 + LLM 모델 로딩 + DB 연결 풀 준비.

```bash
# (1) 헬스체크 — 공개 health endpoint 응답 확인
curl -sS https://ajin-ai-assistant-frontend.vercel.app/api/health | jq

# (2) Compliance 워밍업 — 시나리오 데이터 + 변경 캐시 로드
curl -sS https://ajin-ai-assistant-frontend.vercel.app/api/compliance/changes/recent?limit=5 \
  -H "Authorization: Bearer $JWT" | jq '.[] | .title' | head -3

# (3) Draft 워밍업 — 모델 로드
curl -sS -X POST https://ajin-ai-assistant-frontend.vercel.app/api/draft/preheat \
  -H "Authorization: Bearer $JWT" -m 60

# (4) SPC 데모 시드 (Nelson R1 위반 보장 — §F 시나리오 전제)
cd /Users/yeong/99_me/02_AJIN/ajin-ai-assistant-react
python3 scripts/seed_spc_demo.py --process EWP --inject r1
```

워밍업 통과 기준: 모든 명령이 5초 내 200 응답.

## A. Feature A — 인원 검색 / 조직도 (1분 30초)

**시나리오**: 신입 페르소나가 "안전보건팀 부장이 누구지?" 질문 → 1초 내 검색 + 조직도 표시.

### 시연 절차
1. `/search` 페이지 진입
2. 검색창에 입력: **`안전보건팀 부장`**
3. **0.5초 내** 결과 카드 표시 — 이름/직급/내선/이메일
4. ⌘K 누르고 입력: **`품질보증팀`** → 글로벌 명령 팔레트 동작
5. 좌측 조직도 트리 → "생산본부" 클릭 → 27부서 헤드카운트 표시

### 합격 기준
- 검색 응답 ≤ 1초
- 마스킹: 휴대폰 번호 `010-****-****` 형태
- 내선/사내 이메일은 마스킹 없음

### 어필 포인트
- "기존 엑셀 수동 조회 → 자연어 1초 검색" (신청서 ① 직결)

## B. Feature B — 문서 작성 (3분, **가장 강력한 어필**)

**시나리오 1**: 8D Report 작성 (협력사 클레임 대응)

### 입력값 (고정)
| 필드 | 값 |
|---|---|
| 문서 유형 | `8D Report` |
| 부품번호 | `EWP-2401` |
| 협력사 | `JOON INC (Georgia)` |
| 결함 내용 | `Cracked housing — high voltage leak risk` |
| 톤 | `격식 (외부)` |
| 첨부 항목 | PSW + FMEA + 8D Report Form |

### 시연 절차
1. `/draft` 페이지 진입 → 문서 유형 `8D Report` 선택
2. 위 입력값 입력 → **[생성하기]** 클릭
3. **SSE 스트리밍**: 토큰 단위 응답 실시간 표시 (3~5초 내 완성)
4. 우측 패널에 **자동 채점 5기준 100점 만점** 표시
5. **[다운로드]** 클릭 → 7포맷 중 `DOCX` + `PDF` 시연

### 시나리오 2: OEM 영문 이메일 (1분)
| 필드 | 값 |
|---|---|
| 문서 유형 | `OEM Email` |
| 한국어 입력 | `PPAP Level 3 제출 안내 — 부품 EWP-2401, 기한 2026-06-30` |
| 톤 | `격식 (외부) — 영어` |
| 수신자 | `HMGMA Quality Engineering` |

→ 영어 격식체 초안 + CC 추천 (구매팀 + 품질보증팀)

### 합격 기준
- 초안 생성 시간 ≤ 6초 (스트리밍 첫 토큰 ≤ 1초)
- 7포맷 모두 다운로드 가능
- 채점 점수 ≥ 80점

### 어필 포인트
- "**기존 30분 → 3분, 약 90% 단축**" (신청서 ②, 정량 KPI 직접 입증)
- 7포맷 export로 사내/외부 어떤 시스템과도 호환
- HMGMA(미국 조지아) 영문 커뮤니케이션 = 글로벌 확장 대응

## C. Feature C — AI 업무 도우미 / 챗봇 (1분 30초)

**시나리오**: 신입사원이 사수에게 묻기 어려운 질문 3건을 챗봇에 던짐.

### 시연 절차
1. `/chat` 페이지 진입 → 부서 selectbox: `품질보증팀`, 직급: `사원`
2. 질문 1: **`8D 클레임 대응 어떻게 하나요?`**
   - **0.1초 내** SOP-8D 카드 (5단계) 표시 — 룰 매칭 즉시 응답
   - "Step 1 다시 보기" 버튼 + "다음 퀴즈" 버튼
3. 질문 2: **`PPAP Level 3 단계는?`**
   - SOP-PPAP 카드 표시 + 5문제 자동 생성 퀴즈
4. 질문 3: **`산안법 38조 의무는?`** (LLM 풀 답변 경로)
   - SSE 스트리밍 응답 + 출처 표기 + 신뢰도 점수

### 합격 기준
- 룰/SOP 매칭 응답 ≤ 0.5초
- LLM 응답 첫 토큰 ≤ 2초
- 👍/👎 피드백 버튼 동작

### 어필 포인트
- "**24시간 사수 대체** — 신입 1인당 교육비 2,433만원 절감" (신청서 핵심)
- 부서·직급 RBAC 기반 응답 차등 (보안 컴플라이언스)

## D. Feature D — 법규 모니터링 (3분, **가장 큰 도메인**)

**시나리오**: 안전보건팀 부장이 산안법 38조 개정 발효 임박 상황을 시뮬레이션.

### 시연 절차

#### D-1. 시나리오 시뮬레이션 3종 (60초)
1. `/compliance` 진입 → "법규 업데이트" 탭
2. **시나리오 1**: 산안법 (점수 85)
   - "시뮬레이션 실행" 클릭 → Before/After 비교 + 영향 시설 (경산 본사 프레스 라인) 표시
3. **시나리오 2**: 미국 관세 25% (점수 78)
   - What-if 시뮬레이터 → P&L 영향 + Scope 1/2/3 분리
4. **시나리오 3**: EU REACH (점수 52)
   - 협력사 영향 그래프 + 자가진단 메일 양식

#### D-2. 자연어 RAG Q&A (60초)
1. RAG Q&A 탭 → **`산안법 38조 의무 사항은?`** 입력
2. SSE 스트리밍 응답 + 출처 (조항/섹션) + 영향 등급
3. **자동 후속 작업**: Slack 알림 1건 + Jira 티켓 생성 시뮬레이션

#### D-3. 임원 보고서 자동 생성 (60초)
1. "임원 보고서" 탭 → "분기 보고 생성" 클릭
2. KPI 대시보드 + Top 변경 5건 + 추세 그래프 → PDF 다운로드

### 합격 기준
- 시나리오 시뮬레이션 응답 ≤ 2초
- RAG 첫 토큰 ≤ 3초
- 임원 보고서 PDF 생성 ≤ 5초

### 어필 포인트
- "**컨설팅 1,000만원·2~5개월 → 주 단위로 단축**" (신청서 ③)
- 9종 외부 규제 자동 추적 + What-if 시뮬레이션 5종
- HMGMA/IRA/관세 등 글로벌 확장 대응 키워드 반영

## F. Feature F — 설비·SPC (1분, **데모 모드 필수**)

**사전 조건**: §0의 SPC 데모 시드 (`seed_spc_demo.py --process EWP --inject r1`) 실행되어 EWP 라인이 빨강 신호등 상태여야 함.

### 시연 절차
1. `/equipment` 진입 → "SPC 분석" 탭
2. **5공정 신호등** 표시 (EWP / CCH / 범퍼 / 시트레일 / 도어)
   - **EWP = 빨강** (Nelson R1 위반)
3. EWP 카드 클릭 → Plotly 관리도 + ±3σ 음영 + R1 위반 점 annotation
4. **위반 카드** 표시: "원인/조치/심각도/차트 주석"
5. 챗봇 통합 시연: `/chat` → **`EWP 라인 SPC 어때?`**
   - `spc_status` 액션 자동 디스패치 → 신호등 + 위반 요약 카드

### 합격 기준
- 첫 진입 시 5공정 신호등 ≤ 1초 표시
- EWP 빨강 (R1 위반) 자동 감지
- 챗봇 자연어 디스패치 동작

### 어필 포인트
- "**Nelson 8 규칙 + Markov + XGBoost 금형 수명 ML**" (신청서 ⑤)
- 사무직(검색·문서)와 현장직(SPC·설비) 모두 커버하는 풀스택
