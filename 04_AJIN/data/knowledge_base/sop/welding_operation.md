# 용접 공정 운영 절차

## 1. 목적
본 절차서는 아진산업 용접 공정에서 B-Pillar(AJ-BP-002), A-Panel(AJ-AP-001) 어셈블리 등 차체 용접 부품의 용접 조건 설정, 너깃 검사, 파괴 시험 및 안전수칙을 규정하여 용접 품질을 확보하고 안전한 작업 환경을 유지하는 것을 목적으로 한다.

## 2. 적용 범위
- 스폿 용접 (저항 점용접, Resistance Spot Welding)
- CO2/MAG 아크 용접 (필요 시)
- 프로젝션 용접 (너트/볼트 용접)
- 대상 설비: 로봇 용접기, 정치식 스폿 용접기, 프로젝션 용접기

## 3. 용어 정의
- **너깃 (Nugget)**: 스폿 용접 시 형성되는 용접 핵. 용접 품질의 핵심 지표.
- **너깃 직경 (Nugget Diameter)**: 너깃의 지름. 일반적으로 5√t 이상 요구 (t: 판재 두께).
- **용접 전류 (Welding Current)**: 용접 시 흐르는 전류값 (kA).
- **가압력 (Electrode Force)**: 용접 전극이 모재를 누르는 힘 (kN).
- **통전 시간 (Weld Time)**: 용접 전류가 흐르는 시간 (Cycle, 1cycle = 1/60초).
- **끌 시험 (Chisel Test)**: 끌을 이용한 비파괴 용접 검사 방법.
- **인장 시험 (Tensile Test)**: 용접부 파괴 시험. 너깃 직경 및 파단 모드 확인.

## 4. 절차 (단계별)

### 단계 1: 용접 조건 설정
- Control Plan 및 용접 조건표에서 해당 제품의 용접 조건 확인
- **주요 설정 파라미터**:
  - 용접 전류: 제품별 기준값 (예: AJ-BP-002 B-Pillar 메인 스폿 9.5kA ± 0.5kA)
  - 가압력: 기준값 (예: 3.5kN ± 0.3kN)
  - 통전 시간: 기준값 (예: 12 Cycle)
  - 스퀴즈 타임, 홀드 타임 설정
- 로봇 용접의 경우 용접 프로그램 번호 확인 및 로딩
- 전극(팁) 상태 확인: 마모 시 팁 드레싱 또는 교체
- 냉각수 순환 상태 확인

### 단계 2: 초물검사
- 셋업 후 최초 2 pcs 생산
- **검사 항목**:
  - 외관 검사: 스패터(Spatter), 압흔, 변색, 용접 위치 확인
  - 끌 시험 (Chisel Test): 비파괴로 용접 강도 확인 (지정 포인트)
  - 너깃 직경 측정: 파괴 시험 1 pcs 실시 → 너깃 직경 측정
    - 합격 기준: 너깃 직경 ≥ 5√t (t: 얇은 쪽 판재 두께)
  - 프로젝션 용접: 너트/볼트 토크 시험 (규정 토크 만족 확인)
- 초물 합격 → MES 기록 → 양산 개시
- 불합격 시 → 용접 조건 재조정 후 재검사

### 단계 3: 양산 운영
- 초물 합격 후 양산 가동
- **작업자 자주 검사**:
  - 매 생산품 외관 검사 (스패터, 용접 위치)
  - 매 50 pcs마다 끌 시험 실시 (지정 포인트)
- **순회 검사**: 품질 담당자 매 2시간 순회
- **전극 팁 관리**:
  - 팁 드레싱: 매 200~300 타점마다 실시 (팁 드레서 자동 또는 수동)
  - 팁 교체: 마모 한계 도달 시 교체 (타점 수 기준 관리)
- MES에 생산 실적, 용접 조건 모니터링 데이터 자동 기록
- 용접 조건 이상(전류 이탈, 가압력 저하 등) 알람 발생 시 즉시 정지

### 단계 4: 정기 파괴 시험
- **빈도**: 매 교대(Shift) 시작 시 1 pcs + 교대 종료 시 1 pcs
- **방법**:
  - 용접부 절단 → 너깃 직경 측정 (버니어 캘리퍼스)
  - 인장 시험(필요 시): 용접 강도(kN) 측정
  - 파단 모드 확인: 버튼 파단(양호) vs 계면 파단(불량)
- **기록**: 파괴 시험 성적서 작성 → MES/ERP 등록
- 불합격 시: 해당 교대 생산분 전수 끌 시험 실시 → 부적합품 격리

### 단계 5: 종물검사
- 생산 종료 시 마지막 생산품 검사
- 외관 + 끌 시험 실시
- 종물 합격 기록 후 출하 가능 상태로 전환

### 단계 6: 설비 일상 점검 및 정리
- 전극 팁 상태 확인 및 다음 생산 대비 준비
- 냉각수 누수 점검
- 로봇 원점 복귀 확인
- 용접 건(Gun) 케이블 상태 점검
- 설비 일상 점검 체크시트 작성

## 5. 안전수칙
1. **용접 작업 시 반드시 차광 보안경 또는 용접면 착용** (아크 용접 시 차광도 #10 이상)
2. 용접 스패터 화상 방지를 위해 가죽 장갑, 방열 앞치마 착용
3. 용접 흄(Fume) 흡입 방지를 위해 국소 배기 장치 가동 확인
4. 로봇 용접 셀 안전 펜스 내 진입 시 반드시 로봇 정지 및 안전 플러그 탈거
5. 전극 교체 시 프레스 실린더 하강 방지 조치 (안전 블록 삽입)
6. 냉각수 누수 시 감전 위험 → 즉시 전원 차단 후 정비팀 호출
7. 용접 전류 측정 시 전용 클램프 미터 사용 (맨손 접촉 금지)
8. 비상정지 버튼 위치 숙지 및 매 교대 시 동작 테스트

## 6. 관련 시스템
- **MES**: 생산 실적, 용접 조건 모니터링(전류, 가압력 실시간 로깅), 검사 기록
- **용접 모니터링 시스템**: 용접 전류, 저항값 실시간 감시 및 이상 알람
- **SPC 시스템**: 너깃 직경, 인장 강도 데이터 관리 (Cpk 모니터링)
- **ERP 품질 모듈**: 파괴 시험 성적, 부적합 이력

## 7. FAQ
**Q1. 너깃 직경이 기준 미달이면 어떻게 하나요?**
A1. 즉시 라인을 정지하고 용접 조건(전류, 가압력, 통전 시간)을 재확인합니다. 전극 팁 마모가 주요 원인인 경우가 많으므로 팁 드레싱 또는 교체 후 재검사합니다. 조건 변경 시 생산기술팀 승인이 필요합니다.

**Q2. 끌 시험과 파괴 시험의 차이는?**
A2. 끌 시험은 끌을 용접부에 삽입하여 떨어지지 않는지 확인하는 비파괴 검사입니다. 파괴 시험은 실제로 용접부를 파단시켜 너깃 직경과 파단 모드를 확인하는 검사로, 더 정확한 품질 확인이 가능합니다.

**Q3. 용접 조건을 임의로 변경해도 되나요?**
A3. 절대 불가합니다. 용접 조건 변경은 4M 변경에 해당하며, 반드시 생산기술팀 검토 → 품질팀 승인 → 고객 통보(필요 시) 절차를 거쳐야 합니다. 무단 변경 시 중대 품질 사고로 이어질 수 있습니다.
