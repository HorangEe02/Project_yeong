# 8D Report 작성 절차

## 1. 목적
본 절차서는 현대/기아자동차 및 기타 고객으로부터 접수된 품질 클레임에 대해 8D(8 Disciplines) 방법론을 활용하여 체계적으로 원인을 분석하고 재발 방지 대책을 수립, 회신하는 절차를 규정한다. 아진산업 납품 부품(AJ-EMP-W100, AJ-CCH-H200, AJ-OBC-C300, AJ-AP-001, AJ-BP-002, AJ-CWH-400)에 대한 모든 클레임에 적용한다.

## 2. 적용 범위
- 고객사(현대/기아) 라인 불량 클레임
- 필드(시장) 클레임
- 내부 공정 중대 불량 (Lot 불량률 기준 초과 시)
- 고객 감사 시 발견된 부적합 사항

## 3. 용어 정의
- **8D**: 8 Disciplines. Ford사에서 개발된 문제 해결 기법.
- **클레임**: 고객이 제기하는 품질 불만(Claim).
- **CAR**: Corrective Action Request. 시정 조치 요구서.
- **5Why 분석**: 근본 원인 도출을 위한 반복적 "왜?" 질문 기법.
- **특채(Concession)**: 규격 이탈 제품의 조건부 사용 승인.

## 4. 절차 (단계별)

### 클레임 접수
- 영업팀이 고객으로부터 클레임 접수 (SQ 포털 알림 또는 유선/이메일)
- 영업팀은 접수 즉시 품질관리팀에 클레임 내용 전달 (접수 후 2시간 이내)
- 품질관리팀 클레임 접수 대장(ERP) 등록

### D1: 팀 구성 (Team Formation)
- **기한**: 클레임 접수 후 4시간 이내
- **담당**: 품질관리팀장이 팀 리더 지정
- **구성**: 품질 담당자(리더), 생산기술 담당자, 해당 공정 반장, 필요 시 연구소 담당자
- 팀원 역할 및 연락처를 8D 양식에 기록

### D2: 문제 기술 (Problem Description)
- **기한**: 접수 후 8시간 이내
- **담당**: 품질 담당자(팀 리더)
- 5W2H 기법으로 문제를 명확히 기술
  - What: 어떤 불량인가 (예: AJ-BP-002 B-Pillar 용접 너깃 미형성)
  - When: 언제 발생했는가
  - Where: 어디에서 발견되었는가 (고객 라인, 시장 등)
  - Who: 발견자
  - Why: 왜 문제인가 (규격 대비 이탈 수준)
  - How: 어떻게 발견되었는가
  - How many: 불량 수량, 불량률

### D3: 긴급 대책 (Interim Containment Action)
- **기한**: 접수 후 24시간 이내
- **담당**: 품질 담당자 + 생산기술 담당자
- 고객 라인 재고, 물류 재고, 사내 재고 전수 선별
- 의심 Lot 출하 중지 (ERP 출하 보류 처리)
- 필요 시 고객사 현장 파견하여 선별 작업 실시
- 긴급 대책 실시 결과를 SQ 포털에 1차 회신

### D4: 근본 원인 분석 (Root Cause Analysis)
- **기한**: 접수 후 3일 이내
- **담당**: 품질 담당자 + 생산기술 담당자
- 분석 기법: 5Why 분석, 특성요인도(Fishbone), FTA 등
- 발생 원인(Why Occurred)과 유출 원인(Why Not Detected)을 구분하여 분석
- 현물 확인, MES 생산 이력 추적, 측정 데이터 분석

### D5: 영구 대책 선정 (Permanent Corrective Action Selection)
- **기한**: 접수 후 5일 이내
- **담당**: 생산기술 담당자 + 품질 담당자
- D4에서 도출한 근본 원인에 대한 영구 대책 수립
- 대책의 효과성 검증 방법 결정
- 필요 시 금형 수정, 설비 개조, 검사 강화 계획 포함

### D6: 영구 대책 실행 및 검증 (Implementation & Validation)
- **기한**: 접수 후 14일 이내 (고객 협의에 따라 조정 가능)
- **담당**: 생산기술팀(실행), 품질팀(검증)
- 대책 적용 후 최소 3 Lot 연속 합격 확인
- SPC 데이터로 공정 능력 개선 확인
- 검증 결과를 8D 보고서에 기록

### D7: 재발 방지 (Preventive Action)
- **기한**: D6 완료 후 7일 이내
- **담당**: 품질 담당자
- 유사 공정, 유사 부품으로 수평 전개
- PFMEA, Control Plan 업데이트
- 작업 표준서(WI) 개정
- 교육 실시 및 기록

### D8: 팀 해산 및 완료 (Team Recognition & Close)
- **담당**: 품질관리팀장
- 최종 8D 보고서 완성 → 품질임원 승인
- SQ 포털에 최종 보고서 업로드
- 고객 승인(Close) 확인
- ERP 클레임 대장 마감 처리

## 5. 고객 회신 기한 요약
| 단계 | 기한 | 비고 |
|------|------|------|
| 1차 회신 (D1~D3) | 접수 후 24시간 | SQ 포털 긴급 대책 회신 |
| 중간 보고 (D4~D5) | 접수 후 5일 | 원인 분석 및 대책 방향 |
| 최종 보고 (D6~D8) | 접수 후 14~30일 | 검증 완료 후 최종 회신 |

## 6. 관련 시스템
- **SQ 포털**: 클레임 접수, 8D 보고서 업로드, 승인 상태 관리
- **ERP 품질 모듈**: 클레임 대장, 부적합 이력, 비용 정산
- **MES**: 생산 이력 추적 (Lot No., 작업자, 설비, 자재 Lot)
- **SPC 시스템**: 공정 능력 데이터 확인 및 대책 효과 검증

## 7. FAQ
**Q1. 클레임 접수 후 가장 먼저 해야 할 일은?**
A1. 해당 Lot의 출하를 즉시 보류하고(ERP 출하 보류), 고객 라인 및 물류 재고 현황을 파악하여 선별 계획을 수립하는 것입니다.

**Q2. 5Why 분석이 막힐 때 어떻게 하나요?**
A2. 현장(현물, 현상)을 반드시 직접 확인하고, 관련 작업자 인터뷰, MES 이력 데이터 분석을 병행합니다. 필요 시 특성요인도(4M+E 관점)를 활용하여 원인 후보를 넓힌 뒤 검증합니다.

**Q3. 고객이 기한 내 회신을 독촉하면?**
A3. 현재까지의 분석 진행 상황을 중간 보고 형태로 SQ 포털에 업데이트하고, 완료 예상 일정을 명시합니다. 영업팀을 통해 고객 SQ 담당자와 일정 협의합니다.
