# 수입 검사 (Incoming Inspection) 절차

## 1. 목적
본 절차서는 아진산업에 입고되는 원자재, 부자재, 외주 가공품에 대한 수입 검사 기준과 절차를 규정하여, 부적합 자재가 생산 라인에 투입되는 것을 방지하고, 양산 부품(AJ-EMP-W100, AJ-CCH-H200, AJ-OBC-C300, AJ-AP-001, AJ-BP-002, AJ-CWH-400)의 품질을 확보하는 것을 목적으로 한다.

## 2. 적용 범위
- 원자재 (강판, 알루미늄 소재, 수지류, 전자부품 등)
- 외주 가공품 (도금, 도장, 열처리 외주)
- 구매 부품 (볼트, 너트, 클립, 커넥터 등)
- 포장재 (통함, 폴리백, 라벨 등)

## 3. 용어 정의
- **IQC (Incoming Quality Control)**: 수입 품질 관리.
- **AQL (Acceptable Quality Level)**: 합격 품질 수준. 샘플링 검사 기준.
- **MIL-STD-1916**: 샘플링 검사 규격.
- **COC (Certificate of Conformance)**: 적합 증명서. 협력사 자체 검사 성적서.
- **부적합품**: 검사 기준에 미달하는 자재.
- **특채**: 부적합품을 조건부로 사용 승인하는 것.

## 4. 절차 (단계별)

### 단계 1: 자재 입고 접수
- 자재팀(창고)이 입고된 자재를 ERP 구매 모듈에서 입고 전표 확인
- 납품서, COC(적합 증명서), 자재 시험 성적서(Mill Sheet 등) 수령 확인
- 입고 자재를 수입 검사 대기 구역에 격리 배치
- ERP에 입고 등록 (상태: "검사 대기")

### 단계 2: 검사 대상 분류
- **전수 검사 대상**: 신규 협력사 초도품, 클레임 이력 자재, 특별 관리 자재
- **샘플링 검사 대상**: 정상 납품 자재 (AQL 기준 적용, 일반적으로 AQL 0.65~1.0)
- **무검사(Skip) 대상**: 장기 우수 협력사 인증 자재 (최근 12개월 불량률 0% + 품질팀장 승인)
- 검사 수준은 ERP 자재 마스터에 등록된 검사 등급에 따름

### 단계 3: 검사 실시
- **외관 검사**: 스크래치, 녹, 오염, 변형, 치수 이상 육안 확인
- **치수 검사**: 캘리퍼스, 마이크로미터, 하이트 게이지 등으로 주요 치수 측정
- **재질 검사**: Mill Sheet 성적 확인, 필요 시 경도 시험, 성분 분석
- **기능 검사**: 전자부품의 경우 전기적 특성 검사 (저항, 절연 등)
- 검사 결과를 수입 검사 성적서에 기록

### 단계 4: 합격/부적합 판정
#### 합격 시:
- ERP 상태 변경: "검사 대기" → "합격(사용 가능)"
- 합격 라벨(녹색) 부착 후 자재 창고 입고
- 생산 투입 가능 상태로 전환

#### 부적합 판정 시:
- ERP 상태 변경: "검사 대기" → "부적합(사용 불가)"
- 부적합 라벨(적색) 부착 후 부적합품 격리 구역으로 이동
- 부적합 보고서 작성 (ERP 품질 모듈)
- 협력사에 부적합 통보 및 시정 조치 요구

### 단계 5: 부적합품 처리
- **반품**: 협력사에 반품 처리 (기본 원칙)
- **특채 사용**: 긴급 생산 필요 시 품질팀장 + 생산팀장 합의 후 특채 승인
  - 특채 조건: 기능에 영향 없는 외관 경미 불량 등에 한함
  - 특채 이력 ERP에 기록 (추후 협력사 평가에 반영)
- **선별 사용**: 전수 선별 후 양품만 사용 (선별 비용은 협력사 청구)
- **폐기**: 사용 불가 판정 시 폐기 처리

### 단계 6: ERP 등록 및 이력 관리
- 검사 결과(합격/부적합/특채) ERP에 최종 등록
- 월별 협력사별 수입 검사 실적 집계
- 분기별 협력사 품질 평가에 수입 검사 데이터 반영

## 5. 관련 시스템
- **ERP 구매/품질 모듈**: 입고 등록, 검사 판정, 부적합 관리, 협력사 평가
- **MES**: 자재 Lot 추적 (투입 이력 연동)
- **측정 장비**: 캘리퍼스, 마이크로미터, 하이트 게이지, 경도 시험기

## 6. FAQ
**Q1. 수입 검사에 소요되는 시간은?**
A1. 일반 자재는 입고 후 4시간 이내, 시험이 필요한 자재(경도, 성분 분석 등)는 1영업일 이내 완료를 목표로 합니다.

**Q2. 긴급 입고 시 검사를 생략할 수 있나요?**
A2. 원칙적으로 검사 생략은 불가합니다. 다만 긴급 시 품질팀장 승인 하에 "선 투입, 후 검사" 처리가 가능하며, 반드시 당일 내 검사를 완료하고 이력을 기록해야 합니다.

**Q3. 협력사 COC만으로 합격 처리할 수 있나요?**
A3. 무검사(Skip) 등급으로 지정된 협력사에 한해 COC 기반 합격 처리가 가능합니다. 단, 분기 1회 이상 정기 검증 검사를 실시해야 합니다.
