# 아진산업 채용 절차 안내 (총무인사팀)

본 문서는 신규 인원 채용 요청부터 입사까지의 사내 채용 절차를 정리합니다. 부서장·팀장이 인력을 요청하거나 신입 사원이 입사 일정을 확인할 때 참조합니다.

## 1. 채용 요청 (Request for Hire)

### 1.1 요청 시점
- **정기 채용**: 연 2회 (3월·9월 — 신입/경력 통합)
- **수시 채용**: 결원·신사업·긴급 충원 — 즉시 요청 가능

### 1.2 요청 절차

| 단계 | 내용 | 담당 |
|---|---|---|
| 1 | 인력 요청서 작성 (직무·인원·자격·연봉 범위) | 부서장 |
| 2 | 본부장 검토 + 결재 | 본부장 |
| 3 | 인사관리팀 → 인력 운영회의 상정 | 인사팀 |
| 4 | 임원 승인 (월 1회 정례 회의) | 경영진 |
| 5 | 채용 공고 + 후보 모집 시작 | 인사팀 |

**소요 기간**: 정기 채용 약 8주 / 수시 채용 약 4-6주

## 2. 채용 채널

| 채널 | 용도 | 비고 |
|---|---|---|
| 사람인·잡코리아 | 일반 공개 채용 | 정기 + 수시 |
| 캐치 | 신입·인턴 | 신입 위주 |
| 헤드헌터 | 경력 + 임원급 | 직무 전문성 필요 시 |
| 사내 추천 (RAC) | 전 채용 종류 | 추천자에게 보상금 100만원 |
| KNU 산학협력 | 신입·인턴 | KDT 협업, 매년 30명 |
| 해외 채용 | 해외법인 발령 인원 | HMGMA·중국·베트남 |

## 3. 전형 단계

```
서류 → 인적성 → 직무 면접 → 임원 면접 → 신체검사·신원조회 → 합격
```

| 단계 | 진행 | 평가 |
|---|---|---|
| 서류 | 자기소개서 + 이력서 + 포트폴리오 | 인사팀 1차 + 부서 검토 |
| 인적성 | SK 통합 적성검사 (오프라인) | 통과 70점 이상 |
| 직무 면접 | 부서장 + 선임 2-3명 | 직무 적합성 |
| 임원 면접 | 본부장 + HR 임원 | 인성·컬쳐핏 |
| 신체검사 | 종합검진 + 색약·청력 | 안전 직무 추가 검사 |

**전형 기간**: 정기 약 6-8주 / 수시 약 3-5주

## 4. 입사 / 온보딩

### 4.1 입사 첫날 체크리스트

| 항목 | 처리 부서 |
|---|---|
| 근로계약서 + 보안서약서 | 인사팀 #4001 |
| 카드키 + 사번 발급 | 보안팀 + 인사팀 |
| ERP / 사내 메일 계정 | IT전략팀 |
| 노트북 / 핸드폰 + 자리 | IT전략팀 + 시설관리팀 |
| 4대보험 가입 | 인사팀 |
| 사내 식당 카드 | 시설관리팀 |
| 통근버스 등록 (선택) | 시설관리팀 |

### 4.2 첫 주 OJT
- **D1**: 사내 투어 + 부서 인사 + 인사팀 오리엔테이션 (1일)
- **D2-D3**: 부서별 OJT (사수 배정 + SOP 8종 학습)
- **D4-D5**: 직무 실습 + 첫 회의 참여
- **W2-W4**: 멘토 페어링 + 매주 1회 인사팀 면담

### 4.3 정기 평가
- **수습 평가**: 입사 3개월 후 (정직원 전환)
- **수습 통과율**: 약 95% (직무 부적합 시 재배치 우선)

## 5. 인턴 / 파트타임

| 종류 | 기간 | 전환 가능성 |
|---|---|---|
| 정규 인턴 | 6개월 | 정직원 전환 검토 |
| 학기 인턴 (KNU) | 학기 단위 | 우수 인턴 우선 채용 |
| 산학 협력 인턴 | 1년 | 졸업 후 우선 입사 |
| 단기 파트타임 | 3개월 이하 | 미전환 (직무 한정) |

## 6. 사내 추천 제도 (RAC)

- **추천 가능 직급**: 모든 직급 (단 본인이 면접관/팀장이면 회피)
- **추천 보상금**: 정직원 채용 시 추천자 100만원 (수습 통과 후 지급)
- **공정성 검증**: 인사팀 별도 추적, 동일 추천자 3건 이상 시 재검토
