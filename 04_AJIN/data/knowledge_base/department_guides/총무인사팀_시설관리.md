# 사내 시설 사용 신청 절차 (총무인사팀)

본 문서는 회의실·차량·사옥·게스트하우스 등 사내 시설 사용 신청 절차를 정리합니다.

## 1. 회의실 예약

| 회의실 | 위치 | 수용 | 비고 |
|---|---|---:|---|
| 본관 5F 임원회의실 | 본관 5층 | 12명 | 임원·본부장 우선 / VC 가능 |
| 본관 3F 회의실 A | 본관 3층 | 8명 | 일반 / VC 가능 |
| 본관 3F 회의실 B | 본관 3층 | 6명 | 일반 |
| 본관 1F 비전룸 | 본관 1층 | 30명 | 발표·세미나 전용 / 빔 + 마이크 |
| R&D센터 회의실 | R&D 2층 | 10명 | 김천 R&D 직원 우선 |
| 공장별 현장 회의실 | 각 공장 | 4-8명 | 현장 점검·간담회 |

**예약 채널**: ERP → 시설 → 회의실 예약 → 회의실 + 시작/종료 시각 + 안건
**예약 단위**: 30분 단위, 최소 30분, 최대 4시간 (연장 시 사유 입력)
**취소**: 회의 1시간 전까지 자유 취소, 그 후 자동 노쇼 카운트

## 2. 사내 차량 신청

| 차종 | 용도 | 운영 |
|---|---|---|
| 카니발 (3대) | 단체 출장 / 의전 | 본사 차량팀 — 1주일 전 신청 |
| K5 (5대) | 일반 출장 / 외근 | 본사 차량팀 — 1일 전 |
| 화물차 (1.5톤) | 자재 / 시제품 운반 | 본사 자재팀 협의 |
| 골프카트 | 공장 내 이동 | 각 공장별 운영 |

**예약 채널**: ERP → 시설 → 차량 신청 → 출발지·목적지·시각·인원 + 운전자
**기름값**: 회사 부담 (영수증 첨부)
**보험**: 임직원 운전자 한정. 면허 5년 미만 사원은 사전 차량팀 승인 필요

## 3. 사옥 / 게스트하우스

- **본사 게스트하우스**: 외국인 임원·고객사 방문 시. 본사 정문 옆 별관. 1박 무료
- **R&D 기숙사**: 김천 R&D 발령 사원. 1인 1실. 식비 별도
- **공장 기숙사**: 경주·아산 공장 발령 사원. 2인 1실. 사내 식당 무료

**신청 채널**: 인사관리팀 #4001 + 신원 확인 서류

| 임시 카드 | 협력사·인턴 | 호스트 부서장 승인 + 사용 기간 명시 |
| 외국인 방문증 | 해외법인 임직원 | 보안팀 사전 통보 + 입국일 사진 |
