# 설계변경통보서 (ECN)

| 항목 | 내용 |
|------|------|
| **문서번호** | ECN-2026-003 |
| **발행일** | 2026-03-10 |
| **대상부품** | EMP 워터펌프 임펠러 (Impeller) |
| **품번** | AJ-EMP-IP-1055 |
| **변경유형** | 형상 변경 (유동 최적화) |
| **적용차종** | NE1 (아이오닉5 후속), EV9 후속 |
| **변경요청출처** | 내부 연구과제 - RD-2026-CFD-003 (유량 효율 개선) |

---

## 1. 변경 내용

| 구분 | 변경 전 | 변경 후 |
|------|---------|---------|
| 임펠러 형식 | 폐쇄형 (Closed Type) | 반개방형 (Semi-Open Type) |
| 블레이드 매수 | 6매 | 7매 |
| 블레이드 출구각 (β2) | 25° | 30° |
| 블레이드 두께 | 2.0mm 균일 | 1.5mm~2.2mm 가변 (Leading Edge 박형화) |
| 임펠러 외경 | φ52mm | φ52mm (동일) |
| 설계 유량 | 15 L/min @ 0.5bar | 16.8 L/min @ 0.5bar (+12%) |
| 수력 효율 | 62% | 69.4% (+7.4%p) |
| 소재 | PPS-GF40 (유리섬유 40% 강화) | PPS-GF40 (동일) |

---

## 2. 변경 사유

- CFD(전산유체역학) 해석 기반 임펠러 형상 최적화 과제 수행 결과, 유량 효율 12% 개선 달성
- NE1 및 EV9 후속 차종의 배터리 팩 대용량화(77.4kWh → 84kWh)에 따른 냉각 유량 증가 요구 대응
- 기존 폐쇄형 임펠러 대비 반개방형 구조 적용으로 디스크 마찰 손실 저감
- 블레이드 출구각 최적화(25° → 30°) 및 매수 증가(6 → 7매)로 양정-유량 특성 개선
- Leading Edge 박형화로 유입 충격 손실 감소, 캐비테이션 마진 향상
- 동일 모터 출력으로 유량 12% 증가 달성 → 시스템 에너지 효율 개선 (전비 기여)

---

## 3. 영향 범위

| 영향 항목 | 상세 내용 | 영향도 |
|-----------|-----------|--------|
| **공정** | 임펠러 사출 공정 조건 변경 (반개방형 구조 변경에 따른 게이트 위치 재설정) | 중간 |
| **금형** | 임펠러 사출 금형 신규 제작 (블레이드 형상 전면 변경) | 높음 |
| **검사 기준** | 유량-양정 성능시험 기준 변경, 블레이드 두께 측정 항목 추가 | 중간 |
| **BOM** | 임펠러 품번 변경 (AJ-EMP-IP-1024 → AJ-EMP-IP-1055) | 낮음 |
| **펌프 ASSY** | 임펠러-볼류트 간 클리어런스 재검증 (형상 변경에 따른 간섭 확인) | 중간 |
| **시스템 매칭** | 배터리 냉각 시스템 유량-압력 매칭 재검증 (현대차 협의 필요) | 높음 |
| **내구 시험** | 반개방형 구조 변경에 따른 내구 수명 재검증 (10,000시간 가속 시험) | 높음 |
