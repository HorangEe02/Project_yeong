장민호 차장님, 안녕하십니까.

아진산업 구매팀 윤서영입니다. 새해 복 많이 받으시기 바랍니다.

당사 CCH 냉난방장치에 적용 중인 블로워 모터(귀사 품번: DM-BM-450) 사양 변경 건에 대해 협의를 요청드립니다.

### 사양 변경 배경

기아자동차 GN7 플랫폼向 CCH 냉난방장치 설계변경(ECR-2026-0015)에 따라, 블로워 모터의 정격 사양 변경이 필요합니다.

### 변경 요청 내역

| 항목 | 현행 사양 | 변경 사양 | 비고 |
|------|-----------|-----------|------|
| 정격 전압 | DC 12V | DC 12V | 변경 없음 |
| 정격 전류 | 8A | 10A | 상향 |
| 최대 회전수 | 4,500 rpm | 5,200 rpm | 상향 |
| 커넥터 핀 수 | 4핀 | 6핀 | PWM 제어 추가 |
| 외형 치수 | 변경 없음 | 변경 없음 | 장착 호환 유지 |

### 협의 요청 사항

1. **사양 변경 가능 여부**: 상기 사양으로 변경 생산이 가능한지 검토 부탁드립니다.
2. **단가 영향**: 사양 변경에 따른 단가 변동이 있을 경우 견적 회신 부탁드립니다.
3. **변경 리드타임**: 사양 변경 후 양산 개시까지 예상 소요 기간을 알려주시면 감사하겠습니다.
4. **샘플 납품**: 변경 사양 샘플 50EA를 2026년 1월 20일까지 납품 가능 여부를 확인 부탁드립니다.

### 희망 일정

| 항목 | 일정 |

| 사양 변경 검토 회신 | 2026-01-10 |
| 샘플 납품 | 2026-01-20 |

당사 기술팀과의 대면 협의가 필요하시면 일정을 조율하겠습니다. 빠른 검토와 회신 부탁드리겠습니다.
