# AIDA 2000T 프레스 운영 매뉴얼 (요약)

## 1. 설비 개요
- 모델: AIDA 2000T Servo Press
- 가압력: 2,000 톤
- 스트로크: 최대 500mm
- BPM: 최대 25 spm
- 용도: 자동차 차체 패널 성형 (후드, 도어, 사이드 패널)

## 2. 일상 점검 항목

### 시업 전 점검 (매일)
1. 유압 오일 레벨 확인 (게이지 GREEN 범위)
2. 윤활유 자동급유 장치 정상 확인 (펌프 토출 확인)
3. 안전장치 작동 테스트 (라이트커튼, 양수조작, 안전문)
4. 에어 압력 확인 (5.0~5.5 kgf/cm2)
5. 슬라이드 BDC 확인 (설정값 +/-0.05mm 이내)

### 주간 점검
1. 유압 필터 차압 게이지 확인 (교체 기준: 적색 표시)
2. 가이드 간극 측정 (허용: 0.03~0.08mm)
3. 볼스터/슬라이드 T홈 청소
4. 에어 드레인 배출

## 3. 에러코드 일람

| 코드 | 명칭 | 심각도 | 조치 |
|------|------|--------|------|
| E-001 | 과부하 경보 | 위험 | 즉시 정지, 금형 확인 |
| E-002 | BDC 이상 | 위험 | 즉시 정지, 커넥팅로드 점검 |
| E-010 | 유압 압력 저하 | 경고 | 오일/필터 점검 |
| E-015 | 안전장치 작동 | 위험 | 작업자 확인, 장애물 제거 |
| E-020 | 과열 경보 | 경고 | 냉각 대기, 환기 확인 |

## 4. 금형 셋팅 절차

### 4-1. 금형 장착
1. 슬라이드를 상사점(TDC)으로 이동
2. 볼스터 위 이물질 청소
3. 금형 하형을 볼스터에 안착 (크레인 사용, 2명 이상)
4. T볼트로 하형 고정 (대각선 순서로 조임)
5. 슬라이드 하강하여 상형 위치 확인
6. 상형 클램프 체결
7. 다이하이트 조정 (매뉴얼 모드에서 미세 조정)
8. 안전 블록 삽입 후 최종 확인

### 4-2. 트라이 런 (시험 타발)
1. 인칭(Inching) 모드로 1행정 시운전
2. 소재 투입 없이 금형 간섭 확인
3. 소재 1장 투입 -> 저속 시타 (5 spm)
4. 성형품 치수 측정 (3개소 이상)
5. 정상 확인 후 속도 단계적 증속

## 5. 비상 상황 대응

### 슬라이드 하강 중 멈춤
1. 즉시 비상정지 버튼 확인 (작동 중이면 유지)
2. 유압 게이지 확인 -> 압력 있으면 수동 상승 시도
3. 압력 없으면 수동 펌프로 슬라이드 상승
4. 금형 사이에 소재 끼임 시 -> 금형팀 호출 (무리한 제거 금지)

### 이상 소음 발생
1. 즉시 정지
2. 소음 발생 부위 확인 (가이드, 커넥팅로드, 클러치/브레이크)
3. 금형 간섭 여부 확인
4. 설비팀 연락 -> 정밀 점검 실시

## 6. 윤활 관리

### 자동 윤활 시스템
- 윤활 주기: 30분 간격 자동 급유
- 사용 오일: MOBIL DTE 25 (ISO VG 46)
- 탱크 용량: 200L
- 경고 레벨: 30L 이하 시 경고등 점등

### 윤활 포인트 (수동)
| 부위 | 윤활제 | 주기 |
|------|--------|------|
| 가이드 슬라이드 | 리튬그리스 EP-2 | 주 1회 |
| 커넥팅로드 베어링 | 자동급유 | 연속 |
| 클러치/브레이크 | 전용유 | 6개월 |
| T홈 | 방청유 | 금형교환시 |

## 7. 안전 수칙

1. 금형 교환 시 반드시 안전 블록 삽입
2. 라이트커튼 범위 내 진입 금지 (운전 중)
3. 비상정지 후 원인 확인 없이 리셋 금지
4. 개인 보호구 착용: 안전모, 안전화, 보안경, 귀마개
5. 2인 1조 작업 원칙 (금형 장착, 트라이)
