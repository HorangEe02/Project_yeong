# CNC 선반 운영 매뉴얼 — 두산공작기계 PUMA 2600SY

## 1. 장비 개요

| 항목 | 사양 |
|------|------|
| 모델 | 두산공작기계 PUMA 2600SY |
| 제어기 | FANUC 0i-TF Plus |
| 가공 방식 | CNC 선삭 + Y축 밀링 (복합 가공) |
| 최대 가공 직경 | Φ350 mm |
| 주축 회전수 | 최대 4,500 rpm |
| 공구 수 | 12스테이션 터렛 |
| 적용 부품 | EWP 하우징, CCH 바디, 범퍼빔 브래킷 |

## 2. 일상 점검 체크리스트

### 시작 전 점검 (매일)
- 절삭유(쿨런트) 수위 및 농도 확인 (농도 5~8%)
- 주축 런아웃 확인 (다이얼 게이지, 허용 0.005mm 이내)
- 척(Chuck) 클램핑력 확인 (유압 게이지)
- 터렛 인덱싱 정상 동작 확인
- X/Z/Y축 원점 복귀 수행
- 칩 컨베이어 동작 확인 (칩 배출)

### 주간 점검
- 유압 유닛 오일 레벨 확인
- 공구 마모 상태 점검 (인서트 마모, 치핑)
- 쿨런트 필터 청소/교체
- 가이드웨이 윤활유 유량 확인
- 테일스톡 센터 정렬 확인

### 월간 점검
- 주축 베어링 온도 측정 (정상: 40°C 이하)
- 볼스크류 백래시 측정 (X: 0.005mm, Z: 0.005mm 이내)
- 유압 오일 교체 (연 1~2회, 사용 시간 기준)
- 서보 모터 전류 모니터링 (과부하 징후 확인)

## 4. 공구 관리

### 인서트 교체 기준
| 가공 유형 | 교체 주기 | 마모 한계 |
|----------|----------|---------|
| 황삭 (일반강) | 200~300개 | 플랭크 마모 0.3mm |
| 정삭 (일반강) | 150~200개 | 플랭크 마모 0.2mm |
| 알루미늄 가공 | 500~800개 | 구성인선(BUE) 발생 시 |
| 스테인리스 가공 | 100~150개 | 플랭크 마모 0.2mm |

### 공구 오프셋 보정
1. 시작품(첫 번째 가공물) 외경/내경 측정
2. 측정값 - 목표값 = 보정량
3. CNC 화면 → OFFSET → 해당 공구 번호 → 마모 보정(WEAR) 입력
4. **주의:** 기하 보정(GEOMETRY)은 절대 수정 금지 (초기 세팅 값)

### 공구 수명 관리
- CNC 제어기의 공구 수명 관리 기능 활용 (M 코드)
- 가공 횟수 또는 가공 시간 기준 자동 경고
- 경고 시 즉시 공구 교체 (품질 불량 예방)

## 5. SPC 관련 측정

### 주요 측정 항목 (EWP 하우징 기준)
| 항목 | 규격 | 공차 | 측정 주기 | 측정 장비 |
|------|------|------|----------|----------|
| 내경 (Bore) | Φ25.000 | ±0.050 | 매 10개 | 내경 마이크로미터 |
| 외경 (OD) | Φ80.000 | ±0.030 | 매 10개 | 외경 마이크로미터 |
| 깊이 | 35.000 | ±0.100 | 매 20개 | 깊이 게이지 |
| 표면 조도 | Ra 1.6 이하 | - | 매 50개 | 조도계 |

### Cpk 관리 기준
- 초기 공정 능력: Cpk >= 1.67 (PPAP 승인 기준)
- 양산 중 관리: Cpk >= 1.33 유지
- Cpk < 1.33 시: 즉시 원인 분석 + 조치 (공구 마모, 열변위, 소재 로트 등)

## 6. 비상 상황 대응

### 공구 파손 시
1. 즉시 이송 정지 (`FEED HOLD` 버튼)
2. 주축 정지 (`SPINDLE STOP`)
3. 파손된 인서트 조각 확인 (소재 내부에 박혔는지)
4. 해당 가공물 격리 (파손 시점 이후 전수 검사)
5. 공구 교체 후 오프셋 재설정

### 충돌(Crash) 발생 시
1. 즉시 비상정지
2. 주축, 터렛, 테일스톡 파손 여부 확인
3. **절대 전원 OFF 후 재기동하지 말 것** (위치 데이터 손실 위험)
4. 수동(JOG) 모드에서 안전 위치로 후퇴
5. 볼스크류 백래시 재측정 필수

## 7. 안전 수칙
- 가공 중 도어 열림 금지 (인터록 우회 절대 금지)
- 칩 제거 시 반드시 에어건 + 보안경 착용 (비산 칩 위험)
- 회전 중인 척에 손/공구 접근 금지
- 긴 소재 가공 시 바 피더 가이드 장착 필수 (소재 회전 비산 방지)
- 절삭유 피부 접촉 시 즉시 세척 (피부염 예방)
