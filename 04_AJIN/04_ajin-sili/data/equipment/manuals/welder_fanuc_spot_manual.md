# 스팟 용접기 운영 매뉴얼 — FANUC 서보건 시스템

## 1. 장비 개요

| 항목 | 사양 |
|------|------|
| 모델 | FANUC 서보건 스팟 용접 시스템 |
| 용접 방식 | 저항 스팟 용접 (RSW) |
| 가압력 범위 | 200~600 kgf (서보 모터 제어) |
| 용접 전류 | 최대 15,000A |
| 냉각 방식 | 수냉식 (냉각수 순환) |
| 전극 재질 | Cu-Cr (크롬동) |
| 적용 소재 | SPFC 590~1180, 알루미늄, 핫스탬핑 |

## 2. 일상 점검 체크리스트

### 시작 전 점검 (매일)
- 냉각수 유량 확인 (최소 4L/min 이상)
- 냉각수 온도 확인 (15~25°C 범위)
- 전극 팁 상태 확인 (마모, 변형, 오염)
- 에어 압력 확인 (0.5~0.6 MPa)
- 케이블 및 호스 손상 여부 점검
- 비상정지 버튼 동작 확인

### 주간 점검
- 전극 드레싱 실시 (팁 연마)
- 냉각수 필터 점검/청소
- 용접건 케이블 절연 상태 확인
- 가압력 측정 (가압력 게이지)
- 너겟 직경 테스트 (파괴 검사 1회)

### 월간 점검
- 전극 캡 교체 (마모량 기준: 직경 +1mm 초과 시)
- 용접 변압기 절연저항 측정 (1MΩ 이상)
- 냉각수 교체 및 라인 플러싱
- 서보건 구동부 그리스 점검

## 3. 에러코드 참조

| 에러코드 | 에러명 | 원인 | 조치 |
|---------|--------|------|------|
| WLD-E-001 | 용접 전류 부족 | 전극 마모, 가압력 부족, 소재 표면 오염 | 전극 드레싱/교체, 가압력 재설정, 소재 세척 |
| WLD-E-002 | 냉각수 유량 이상 | 냉각수 부족, 필터 막힘, 펌프 고장 | 냉각수 보충, 필터 청소, 펌프 점검 |
| WLD-E-003 | 너겟 직경 미달 | 전류 부족, 통전 시간 짧음, 전극 편심 | 용접 조건 상향, 통전 시간 증가, 전극 정렬 |

| WLD-E-005 | 서보건 과부하 | 연속 가동 과열, 감속기 마모 | 냉각 대기 후 재가동, 감속기 점검 |

## 4. 너겟 품질 관리

### 너겟 직경 기준 (IATF 16949)
- 최소 너겟 직경: 4√t (t = 판두께 mm)
- 예: 1.2mm 판재 → 최소 4 x √1.2 = 4.38mm
- 목표 너겟 직경: 5√t (최적 용접 조건)

### 파괴 검사 주기
- 양산 시작 시: 최초 5타점 전수 파괴 검사
- 양산 중: 매 교대 시작 시 1회 + 4시간 간격 1회
- 전극 교체 후: 즉시 1회 파괴 검사

### 스패터 관리
- 스패터 발생 시 즉시 원인 분석 (전류/가압력/소재 갭)
- 용접 비산물이 부품 기능면에 부착되면 NG 처리
- 방스패터 오일 도포 주기: 매 2시간

## 5. 비상 상황 대응

### 냉각수 누수 시
1. 즉시 용접 정지
2. 냉각수 공급 밸브 차단
3. 전기 배선 접촉 여부 확인 (감전 위험)
4. 안전보건팀 신고
5. 누수 부위 수리 후 절연저항 측정

### 전극 용착 시 (전극이 소재에 붙음)
1. 가압력 해제 (서보건 후퇴)
2. 강제 분리 시도 금지 (전극 파손 위험)
3. 전극 냉각 후 회전 분리 또는 교체
4. 용착 원인 분석 (가압력, 전류, 소재 상태)

## 6. 안전 수칙
- 용접 작업 시 차광 안경 필수 착용 (스패터 비산 위험)
- 냉각수 배관 작업 시 전원 차단 필수 (감전 위험)
- 전극 교체 시 반드시 잔류 전하 방전 확인
- 용접건 이동 반경 내 인원 통제
- 화상 주의: 용접 직후 전극/소재 온도 200°C 이상
