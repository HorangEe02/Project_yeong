# 산업용 로봇 운영 매뉴얼 — FANUC M-20iD/25

## 1. 장비 개요

| 항목 | 사양 |
|------|------|
| 모델 | FANUC M-20iD/25 |
| 컨트롤러 | R-30iB Plus |
| 가반하중 | 25 kg |
| 동작 범위 | 1,831 mm (최대 도달) |
| 축 수 | 6축 다관절 |
| 반복 정밀도 | ±0.04 mm |
| 적용 공정 | 스팟 용접, 아크 용접, 핸들링, 실링 |

## 2. 일상 점검 체크리스트

### 시작 전 점검 (매일)
- 비상정지 버튼 동작 확인 (티치 펜던트 + 외부)
- 원점 복귀(Home Position) 정상 수행 확인
- 서보 모터 이상음 확인 (각 축 저속 동작)
- 에어 공급 압력 확인 (0.5 MPa 이상)
- 그리퍼/용접건 장착 상태 확인
- 안전 펜스 도어 인터록 동작 확인

### 주간 점검
- 각 축 케이블 외관 점검 (꺾임, 피복 손상)
- 감속기 이음 확인 (J1~J6 축 저속 구동)
- 그리퍼 클램프력 측정
- 티칭 프로그램 백업 (USB 또는 네트워크)
- 원점 위치 편차 확인 (마스터링 값 대조)

### 월간 점검
- J1~J3 축 감속기 그리스 주입 (리튬 그리스)
- 배터리 전압 확인 (3.6V — 엔코더 백업용)
- 브레이크 유격 점검 (각 축 브레이크 테스트)
- 케이블 드레스팩 마모 확인 (특히 J4~J6)

|---------|--------|------|------|
| SRVO-001 | 서보 과부하 | 과도한 부하, 충돌, 감속기 마모 | 부하 확인, 충돌 점검, 감속기 교체 검토 |
| SRVO-023 | 축 위치 편차 | 엔코더 이상, 배터리 방전, 기계적 유격 | 마스터링 재수행, 배터리 교체, 백래시 확인 |
| SRVO-050 | 충돌 감지 | 외부 물체 간섭, 지그 위치 이동, 프로그램 오류 | 간섭 물체 제거, 지그 원점 확인, 경로 수정 |

## 4. 티칭 기본 절차

### 티칭 모드 진입
1. 티치 펜던트의 모드 키를 **T1** (저속 수동) 위치로 전환
2. 데드맨 스위치를 중간까지 누른 상태에서만 로봇 동작
3. 이동 속도 제한: T1 모드 최대 250 mm/sec

### 포인트 저장
1. 조그(JOG) 키로 목표 위치까지 로봇 이동
2. `SHIFT + RECORD` 버튼으로 현재 위치 저장
3. 위치 번호(P[1], P[2], ...) 자동 할당
4. 전체 경로 확인: `FWD` 키로 저속 재생

### 프로그램 실행
1. 모드 키를 **AUTO** 위치로 전환
2. 티치 펜던트 **REMOTE** 모드 설정
3. PLC에서 프로그램 번호 + 시작 신호 전송
4. 사이클 완료 후 홈 포지션 복귀

## 5. 비상 상황 대응

### 충돌 발생 시
1. 즉시 비상정지 버튼 누르기
2. **절대 수동으로 로봇을 밀지 말 것** (감속기 파손 위험)
3. 충돌 원인 확인 (소재 위치, 지그 상태, 프로그램 경로)
4. T1 모드에서 저속으로 간섭 구간 탈출
5. 충돌 후 반드시 마스터링 값 확인 (축 위치 틀어짐 가능성)

### 서보 에러 발생 시
1. 에러 코드 확인 (티치 펜던트 ALARM 화면)
2. `FAULT RESET` 시도 (경미한 에러인 경우 해제)
3. 반복 발생 시 해당 축 감속기/모터 점검 의뢰
4. 에러 이력 기록 (발생 시각, 동작 중이던 프로그램, 축 번호)

## 6. 안전 수칙
- **안전 펜스 내부 진입 시 반드시 로봇 정지** (T1 모드 전환 + 비상정지)
- 데드맨 스위치 없이 티칭 금지 (인터록 무효화 절대 금지)
- 자동 운전 중 안전 펜스 도어 열림 시 즉시 정지 (인터록)
- 로봇 동작 반경(1,831mm) 내 적재물/공구 방치 금지
- 월 1회 안전 교육: 비상정지 위치 + 탈출 경로 숙지
