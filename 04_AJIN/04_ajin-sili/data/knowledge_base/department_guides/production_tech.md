# 생산기술팀 신입사원 가이드

## 1. 부서 소개
생산기술팀은 아진산업의 제조 공정을 설계, 구축, 유지/개선하는 부서입니다. 프레스, 용접, 조립 등 전 공정의 기술적 기반을 담당하며, 신규 부품 양산 준비부터 양산 중 공정 최적화, 금형/설비 관리, 4M 변경 관리까지 제조 현장의 기술적 문제를 총괄합니다.

생산하는 주요 제품은 EMP 워터펌프(AJ-EMP-W100), CCH 공조장치(AJ-CCH-H200), OBC 충전기(AJ-OBC-C300), A-Panel(AJ-AP-001), B-Pillar(AJ-BP-002), 냉각수 히터(AJ-CWH-400)이며, 각 제품의 공정 특성이 다르므로 폭넓은 기술 이해가 필요합니다.

팀 내부는 **공정설계 파트**, **금형관리 파트**, **설비보전 파트**로 구성됩니다.

## 2. 주요 업무

### 공정 설계
- **신규 부품 공정 설계**: 연구소 도면을 기반으로 양산 공정 흐름도(Process Flow Diagram) 작성
- **공정 FMEA (PFMEA) 작성**: 품질팀과 공동으로 공정 위험 분석 및 관리 방안 수립
- **작업 표준서(WI) 작성**: 각 공정별 작업 방법, 조건, 검사 항목을 문서화
- **라인 레이아웃 설계**: 생산 효율성과 물류 동선을 고려한 라인 배치
- **공정 조건 최적화**: 프레스(BHF, SPM), 용접(전류, 가압력, 통전 시간) 등 최적 조건 설정
- **SMED 활동**: 금형 교체 시간 단축을 위한 개선 활동

### 금형 관리
- **금형 설계 검토**: 신규 금형 제작 시 설계 검토 (연구소, 금형 업체 협업)
- **금형 예방 보전**: 정기 점검 주기 설정 및 실행 (타수 기반 관리)
- **금형 수리/수정**: 양산 중 금형 문제(마모, 파손, 크랙 등) 발생 시 수리
- **금형 이력 관리**: ERP에 금형별 사용 타수, 수리 이력, 부품 교체 이력 기록
- **금형 보관 관리**: 금형 보관소 온습도 관리, 방청 처리

### 설비 보전
- **예방 보전 (PM: Preventive Maintenance)**: 설비별 PM 계획 수립 및 실행
- **돌발 보전 (BM: Breakdown Maintenance)**: 설비 고장 시 긴급 수리 및 원인 분석
- **설비 정기 교정**: 측정 장비(CMM, 캘리퍼스 등) 정기 교정 관리
- **설비 도입**: 신규 설비 사양 검토, 발주, 설치, 검증(IQ/OQ/PQ)
- **설비 일상 점검**: 작업자 일상 점검 기준 수립 및 교육

### 4M 변경 관리
- 4M(Man, Machine, Material, Method) 변경 발생 시 영향도 평가
- 품질팀과 협의하여 고객 사전 통보 여부 결정
- 변경 전/후 품질 검증 (초물검사, SPC 비교)

## 3. 첫 주에 알아야 할 것

### 반드시 숙지할 시스템
1. **MES**: 생산 계획/실적, 설비 가동률, 금형 타수, 용접 모니터링 데이터 등 현장 데이터의 보고
2. **ERP 생산/설비 모듈**: 금형 이력, 설비 보전 이력, BOM 관리
3. **CAD/CAM**: 금형 도면 확인 및 수정 시 활용 (CATIA 또는 NX)

### 첫 주 필수 활동
- 공장 전 공정 라인 투어 (각 설비 명칭, 위치, 담당자 파악)
- 프레스 라인 금형 셋업 과정 참관 (금형반과 동행)
- 용접 라인 용접 조건 설정 과정 참관
- 각 제품별 공정 흐름도(PFD) 숙독
- 주요 설비 스펙 확인 (프레스 톤수, 용접기 용량 등)
- 안전 교육 이수 (프레스 안전, 용접 안전, LOTO 절차)

### 알아야 할 핵심 문서
- 각 제품별 공정 흐름도 (Process Flow Diagram)
- PFMEA
- 작업 표준서 (Work Instruction)
- 금형 이력 카드
- 설비 PM 계획표
- 용접 조건표

## 4. 주요 협업 부서

| 협업 부서 | 협업 내용 | 빈도 |
|-----------|-----------|------|
| **품질관리팀** | 공정 불량 원인 분석, PFMEA/Control Plan 공동 작성, 4M 변경 협의 | 매일 |
| **연구소** | 신규 부품 도면 검토, 금형 설계 협의, ECR/ECN 기술 검토 | 프로젝트별 |
| **생산팀** | 라인 운영 지원, 설비 트러블 대응, 작업자 교육 | 매일 |
| **구매팀** | 금형 외주 발주, 설비 부품 구매, 신규 설비 도입 | 수시 |
| **영업팀** | 신규 수주 부품 생산 가능성 검토, 시작품 일정 협의 | 프로젝트별 |

## 5. 자주 하는 실수 & 꿀팁

### 자주 하는 실수
1. **4M 변경 미통보**: 설비 수리 후 조건이 미세하게 바뀌었는데 품질팀/고객에게 통보하지 않아 문제 발생. 사소한 변경도 반드시 기록하고 품질팀과 협의.
2. **금형 타수 미기록**: MES에 금형 사용 타수를 기록하지 않으면 예방 보전 시기를 놓쳐 양산 중 금형 파손 사고 발생.
3. **용접 조건 무단 변경**: 현장에서 작업자가 임의로 용접 전류를 올리는 경우 발생. 조건 변경은 반드시 생산기술팀 검토 → 품질팀 승인 절차를 거쳐야 함.
4. **PFMEA를 한 번 작성하고 방치**: PFMEA는 클레임, 공정 변경 시마다 업데이트해야 하는 Living Document. 방치하면 심사 시 지적 사항.
5. **설비 PM 일정 미준수**: "생산이 바쁘니까 다음에"라고 PM을 미루면 돌발 고장으로 더 큰 손실 발생.

### 꿀팁
1. **현장 출근을 습관화**: 사무실에서 데이터만 보지 말고, 매일 아침 현장을 돌며 설비/금형 상태를 눈으로 확인하는 습관이 중요.
2. **금형 수리 시 Before/After 사진 촬영**: 수리 전후 사진을 반드시 남기면 이력 관리와 품질 근거 자료로 활용 가능.
3. **프레스 공정 조건표를 항상 최신으로**: Control Plan과 실제 현장 조건이 다르면 심사 시 부적합. 변경 시 즉시 문서 업데이트.
4. **설비 업체 연락처 정리**: 긴급 고장 시 빠른 대응을 위해 주요 설비 업체 A/S 연락처를 개인 메모로 관리.
5. **SMED 활동 기록 유지**: 금형 교체 시간 단축 활동은 원가 절감 실적으로 인정받으므로, 개선 전/후 데이터를 꼼꼼히 기록.
6. **타 공장 벤치마킹**: 현대/기아 협력사 간 품질 교류회에 적극 참여하면 선진 공정 기술을 배울 수 있는 좋은 기회.
