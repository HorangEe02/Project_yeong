# 품질관리팀 신입사원 가이드

## 1. 부서 소개
품질관리팀은 아진산업에서 생산하는 모든 자동차 부품(EMP 워터펌프 AJ-EMP-W100, CCH 공조장치 AJ-CCH-H200, OBC 충전기 AJ-OBC-C300, A-Panel AJ-AP-001, B-Pillar AJ-BP-002, 냉각수 히터 AJ-CWH-400)의 품질을 총괄 관리하는 핵심 부서입니다. 고객(현대/기아자동차)의 품질 요구사항을 충족하고, 사내 공정 품질을 유지/개선하며, 품질 관련 인증 심사에 대응하는 것이 주요 미션입니다.

품질관리팀은 크게 **고객 품질(CQA)**, **공정 품질(PQA)**, **수입 품질(IQC)** 3개 파트로 구성됩니다.

## 2. 주요 업무

### 고객 품질 (CQA: Customer Quality Assurance)
- **PPAP 관리**: 신규/변경 부품의 PPAP 서류 작성 및 SQ 포털 제출 (18개 서류 취합)
- **8D Report 대응**: 고객 클레임 접수 → 원인 분석 → 시정 조치 → SQ 포털 회신
- **고객 심사 대응**: 현대/기아 SQ 정기 심사, 특별 심사 대응
- **SQ 포털 관리**: 고객 품질 포털 일상 모니터링, 서류 업로드, 승인 상태 관리

### 공정 품질 (PQA: Process Quality Assurance)
- **SPC 관리**: 주요 특별 특성(SC/CC) 항목에 대한 통계적 공정 관리
- **순회 검사**: 프레스, 용접, 조립 라인 정기 순회 검사 실시
- **부적합 관리**: 사내 부적합품 발생 시 원인 분석 및 시정 조치
- **PFMEA / Control Plan 유지 관리**: 공정 변경 시 문서 업데이트
- **초물/종물 검사 관리**: 각 공정 초물/종물 검사 기준 수립 및 결과 확인

### 수입 품질 (IQC: Incoming Quality Control)
- **수입 검사**: 원자재, 외주품, 구매 부품 입고 검사 실시
- **협력사 품질 관리**: 협력사 정기 평가, 부적합 시 시정 조치 요구
- **협력사 심사**: 신규 협력사 승인 심사, 기존 협력사 정기 심사

### 인증/심사 관련
- **IATF 16949 인증 유지**: 내부 심사, 외부 심사 대응
- **고객 특별 심사**: 중대 클레임 발생 시 고객사 특별 심사 대응

## 3. 첫 주에 알아야 할 것

### 반드시 숙지할 시스템
1. **SQ 포털 (https://sq.hyundai.com)**: 품질팀의 핵심 시스템. 클레임 확인, PPAP 제출, 8D 회신 등 모든 고객 커뮤니케이션의 창구. 선배에게 계정 발급 요청 필요.
2. **ERP 품질 모듈**: 부적합 관리, 클레임 대장, PPAP 이력, 검사 성적 관리
3. **MES**: 생산 이력 추적. 클레임 분석 시 해당 Lot의 생산 조건(설비, 작업자, 자재 Lot)을 조회할 때 필수.
4. **SPC 시스템**: 공정 능력 데이터 조회 및 관리 차트 확인

### 첫 주 필수 활동
- 공장 전 공정 라인 투어 (프레스 → 용접 → 조립 → 검사 → 출하)
- 각 제품(AJ-EMP-W100 ~ AJ-CWH-400) 실물 확인 및 주요 품질 특성 학습
- SQ 포털 로그인 및 기본 기능 실습 (선배 동행)
- 최근 6개월 클레임 이력 검토 (빈발 불량 유형 파악)
- IATF 16949 품질 매뉴얼 통독

### 알아야 할 핵심 문서
- 품질 매뉴얼 (QM-001)
- 각 제품별 Control Plan
- PFMEA
- 검사 기준서 (도면 + 한도 견본 사진)

## 4. 주요 협업 부서

| 협업 부서 | 협업 내용 | 빈도 |
|-----------|-----------|------|
| **영업팀** | 클레임 접수/전달, 고객 방문 일정, 납기 영향 협의 | 수시 (클레임 발생 시) |
| **생산기술팀** | 공정 불량 원인 분석, 4M 변경 검토, 설비 관련 품질 이슈 | 매일 |
| **연구소** | PPAP 서류(DFMEA, 도면), ECR/ECN 검토, 신규 부품 품질 기준 | 프로젝트별 |
| **생산팀** | 라인 품질 이슈, 작업자 교육, 부적합품 격리/처리 | 매일 |
| **구매팀** | 협력사 품질 이슈, 수입 검사 부적합 처리 | 주 1~2회 |

## 5. 자주 하는 실수 & 꿀팁

### 자주 하는 실수
1. **SQ 포털 회신 기한 놓침**: 클레임 접수 후 24시간 이내 1차 회신 필수. 기한 초과 시 감점 및 고객 불만 급증.
2. **8D에서 발생 원인과 유출 원인 혼동**: "왜 불량이 발생했는가"와 "왜 불량을 검출하지 못했는가"를 반드시 구분하여 분석해야 합니다.
3. **PPAP 서류 Rev. 불일치**: 도면 Rev.와 Control Plan Rev.가 다른 경우 고객 반려. 제출 전 최신 Rev. 일치 여부 반드시 확인.
4. **MES 이력 미확인**: 클레임 분석 시 MES 생산 이력을 확인하지 않고 추정으로 원인 분석하면 고객에게 신뢰를 잃음.
5. **부적합품 식별 미흡**: 부적합품에 적색 라벨 미부착 시 양품과 혼입되어 유출 사고 발생.

### 꿀팁
1. **SQ 포털 알림 설정**: 이메일/SMS 알림을 반드시 설정하여 클레임 접수 즉시 인지.
2. **클레임 접수 시 현물 확보가 최우선**: 고객으로부터 불량 현물(또는 사진)을 반드시 확보 → 현물 없이 분석하면 시간 낭비.
3. **5Why 분석 시 "작업자 실수"에서 멈추지 말 것**: 작업자가 왜 실수할 수밖에 없었는지(시스템, 환경, 교육 부족 등)까지 파고들어야 근본 원인.
4. **Control Plan은 살아있는 문서**: 클레임/부적합 발생 시마다 Control Plan 업데이트 여부를 검토하는 습관.
5. **고객 심사 전 최소 2주 전부터 준비**: 심사 체크리스트 기반으로 현장 정리, 문서 정비, 모의 심사 실시.
6. **선배의 이전 8D 보고서 참고**: 과거 유사 클레임 8D를 ERP에서 검색하면 분석 방향과 양식 참고에 매우 유용.
