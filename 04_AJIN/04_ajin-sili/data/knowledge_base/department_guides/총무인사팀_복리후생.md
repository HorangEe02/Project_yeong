# 아진산업 사내 복리후생 항목 안내 (총무인사팀)

본 문서는 신입·재직 사원에게 안내하는 사내 복리후생 항목을 정리합니다. 변경·신규 항목은 인사관리팀 공지를 우선합니다.

## 1. 휴가 제도

| 항목 | 내용 |
|---|---|
| 연차 | 입사 1년 미만 월 1일 발생 (최대 11일), 1년 이상 15일 + 가산. 회계연도 기준. |
| 반차 | 오전(09–13)·오후(14–18) 2회 분할 사용 가능. 연차 0.5일 차감. |
| 경조사 휴가 | 결혼 5일 / 자녀 출생 10일 / 부모·배우자 사망 5일 / 형제자매 사망 3일 |
| 출산·육아휴직 | 법정 90일 + 사내 가산. 육아휴직 최대 1년 (남녀 모두) |
| 연차 이월 | 미사용 연차 차년도 6월까지 이월 가능. 그 외는 자동 소진 |

## 2. 보험 / 의료

- **4대 사회보험**: 건강·국민연금·고용·산재 100% 가입
- **단체상해보험**: 본인 + 배우자 + 자녀 (사내 부담)
- **건강검진**: 매년 1회 종합 검진 (본인) + 격년 1회 (배우자)
- **의료비 지원**: 본인 입원 시 자기부담금의 50% (연 200만원 한도)

## 3. 식대 / 통근

- **사내식당**: 본사·공장 무료. 조식·중식·석식 운영 (야간 근무자 한정)
- **통근버스**: 경산↔대구·경산↔영천 등 주요 노선 6개 (편도 1,000원)
- **출장 식대**: 국내 30,000원/일 / 해외 80 USD/일

## 4. 자녀 / 가족

- **학자금 지원**: 자녀 고교·대학 학비 지원 (재직 5년 이상, 연 1,200만원 한도)
- **유치원·어린이집 지원**: 월 30만원 (만 7세 미만)
- **사내 동아리**: 회사 지원금 + 활동비 분기당 30만원

## 5. 주거 / 자기개발

- **사내 아파트**: 신혼·미혼 사원 대상 임대 (전세금 80% 무이자)
- **자기개발비**: 어학·자격증 시험·도서비 연 100만원
- **사내 도서관**: 본사 1F, 1만 권 + 전자책 구독 (Riss·KISS)

## 6. 휴양 / 여가

- **사내 콘도**: 강원·제주·여수 4개소 회원권 (예약제, 1박 50,000원)
- **명절 선물**: 설·추석 + 창립일(8/24) 선물 (3회/년)
- **체육시설**: 본사 헬스장 + 사우나 무료, 천안·광주 공장 별도 운영
- **임직원 해외여행**: 격년 1회 사내 지원 (KBS 출연 사례 참조)

## 7. 신청 방법

| 항목 | 신청 채널 | 처리 |
|---|---|---|
| 연차/반차 | ERP → 인사 → 휴가 신청 | 부서장 결재 |
| 경조사 | 인사관리팀 직통 (#4001) | 24시간 내 처리 |
| 학자금 | 인사관리팀 양식 + 가족관계증명서 | 분기 1회 일괄 |
| 사내 콘도 | 사내 게시판 → 콘도 예약 | 선착순 |
| 의료비 | 인사관리팀 + 영수증 원본 | 월 1회 결산 |
