# PPAP (Production Part Approval Process) 진행 절차

## 1. 목적
본 절차서는 아진산업(주)에서 현대/기아자동차에 납품하는 양산 부품(EMP 워터펌프 AJ-EMP-W100, CCH 공조장치 AJ-CCH-H200, OBC 충전기 AJ-OBC-C300, A-Panel AJ-AP-001, B-Pillar AJ-BP-002, 냉각수 히터 AJ-CWH-400 등)의 PPAP 승인 절차를 규정하여, 고객 요구사항에 부합하는 제출 서류를 적기에 준비하고 승인받는 것을 목적으로 한다.

## 2. 적용 범위
- 신규 부품 양산 개시 시
- 설계 변경(ECN) 적용 후 양산 재개 시
- 공정, 자재, 설비 등 4M 변경 발생 시
- 고객 요청에 의한 재승인 시

## 3. 용어 정의
- **PPAP**: Production Part Approval Process. 양산 부품 승인 프로세스.
- **PSW**: Part Submission Warrant. 부품 제출 보증서.
- **PFMEA**: 공정 고장 모드 영향 분석.
- **SQ 포털**: 현대/기아자동차 협력사 품질 관리 시스템(Supplier Quality Portal).
- **MSA**: 측정 시스템 분석.
- **Cpk**: 공정 능력 지수. 양산 조건에서 1.33 이상 요구.

## 4. PPAP 18개 제출 서류
| No. | 서류명 | 비고 |
|-----|--------|------|
| 1 | 설계 도면 (Design Records) | 고객 승인 도면 최신 Rev. |
| 2 | 승인된 설계 변경 문서 | ECN/ECR 이력 포함 |
| 3 | 고객 엔지니어링 승인 | 필요 시 |
| 4 | 설계 FMEA (DFMEA) | 연구소 주관 |
| 5 | 공정 흐름도 (Process Flow Diagram) | 생산기술팀 작성 |
| 6 | 공정 FMEA (PFMEA) | 품질팀 + 생산기술팀 공동 |
| 7 | 관리 계획서 (Control Plan) | 시작/양산 구분 |
| 8 | MSA (측정 시스템 분석) | GR&R 등 |
| 9 | 치수 검사 결과 | 전수 또는 샘플 |
| 10 | 재료/성능 시험 결과 | 외부 공인시험 포함 |
| 11 | 초기 공정 능력 조사 (SPC) | Cpk ≥ 1.33 |
| 12 | 공인 시험소 성적서 | KS, ISO 인정 시험소 |
| 13 | AAR (외관 승인 보고서) | 외관 부품 해당 시 |
| 14 | 양산 샘플 | 고객 지정 수량 |
| 15 | 마스터 샘플 | 보관 관리 |
| 16 | 검사 보조구 (Checking Aids) | 게이지, 치구 등 |
| 17 | 고객 고유 요구사항 | 현대/기아 SQ 매뉴얼 참조 |
| 18 | PSW (부품 제출 보증서) | 최종 서명 후 제출 |

## 5. PPAP 레벨 구분
- **Level 1**: PSW만 제출 (보증서만 고객에게 제출, 나머지 자체 보관)
- **Level 2**: PSW + 샘플 + 일부 서류 제출
- **Level 3**: PSW + 샘플 + 전체 서류 제출 (현대/기아 기본 요구 레벨)
- **Level 4**: PSW + 고객 지정 서류
- **Level 5**: PSW + 샘플 + 전체 서류 (현장 검토 포함)

## 6. 절차 (단계별)

### 단계 1: PPAP 요구사항 확인
- 고객(현대/기아) 또는 SQ 포털에서 PPAP 요구 레벨 및 제출 기한 확인
- 담당: 품질관리팀 PPAP 담당자

### 단계 2: 서류 작성 계획 수립
- 18개 서류 작성 담당 부서 배정 및 일정표 수립
- 연구소(DFMEA, 도면), 생산기술팀(공정 흐름도, PFMEA 공동), 품질팀(Control Plan, MSA, SPC)

### 단계 3: 시작품 생산 및 검증
- 양산 동일 조건(금형, 설비, 작업자)으로 시작품 최소 300 pcs 생산
- 치수 측정(CMM 활용), 재료 시험, 성능 시험 수행

### 단계 4: 초기 공정 능력 분석
- 주요 특별 특성(SC, CC 항목)에 대해 SPC 분석 실시
- Cpk 1.33 미만 시 공정 개선 후 재측정

### 단계 5: 서류 취합 및 내부 검토
- 품질관리팀에서 전체 서류 취합
- 팀장 → 품질임원 내부 승인

### 단계 6: SQ 포털 제출
- 현대/기아 SQ 포털(https://sq.hyundai.com)에 전자 서류 업로드
- PSW 원본은 별도 우편 또는 직접 전달

### 단계 7: 고객 심사 및 승인
- 고객 SQ팀 서류 검토 → 보완 요청 시 수정 후 재제출
- 승인(Full Approval), 조건부 승인(Interim Approval), 반려(Reject) 판정

### 단계 8: 승인 후 관리
- 승인 서류 ERP(품질 모듈)에 등록 및 보관 (최소 15년)
- 마스터 샘플 품질팀 샘플룸 보관

## 7. 관련 시스템
- **SQ 포털**: PPAP 서류 업로드 및 승인 상태 조회
- **ERP 품질 모듈**: PPAP 이력 관리, 서류 보관
- **MES**: 시작품 생산 이력 추적
- **CMM 측정기**: 치수 검사 데이터 자동 연동

## 8. FAQ
**Q1. PPAP 제출 기한은 보통 언제인가요?**
A1. 현대/기아의 경우 양산 개시(SOP) 8주 전까지 제출이 기본이며, SQ 포털에서 개별 일정을 확인해야 합니다.

**Q2. Cpk가 1.33 미만이면 어떻게 하나요?**
A2. 공정 개선 활동 후 재측정합니다. 불가피한 경우 고객에게 Interim Approval(조건부 승인)을 요청하고, 개선 일정을 포함한 시정조치 계획서를 함께 제출합니다.

**Q3. 4M 변경 시에도 PPAP를 다시 해야 하나요?**
A3. 네. 자재(Material), 설비(Machine), 공법(Method), 작업자(Man) 중 변경 발생 시 변경 영향도 평가 후 고객에게 사전 통보하고, 요구 레벨에 맞는 PPAP를 재진행합니다.

**Q4. Level 3와 Level 5의 차이는?**
A4. Level 5는 Level 3의 모든 서류에 추가로 고객이 당사 현장을 직접 방문하여 공정을 검토하는 단계가 포함됩니다.
