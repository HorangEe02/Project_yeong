# ECN (Engineering Change Notice) 처리 절차

## 1. 목적
본 절차서는 아진산업에서 생산하는 자동차 부품(AJ-EMP-W100, AJ-CCH-H200, AJ-OBC-C300, AJ-AP-001, AJ-BP-002, AJ-CWH-400)의 설계 변경이 발생할 때, ECR(Engineering Change Request) 발의부터 ECN 발행, 양산 적용까지의 전 과정을 규정하여 변경 사항이 누락 없이 관리되고 품질에 미치는 영향을 최소화하는 것을 목적으로 한다.

## 2. 적용 범위
- 고객(현대/기아) 설계 변경 요청에 의한 변경
- 사내 원가 절감, 품질 개선 목적의 자체 변경 제안
- 자재 변경(대체재 적용)
- 공정 변경(설비, 금형, 공법 변경)
- 클레임 대응을 위한 긴급 설계 변경

## 3. 용어 정의
- **ECR (Engineering Change Request)**: 설계 변경 요청서. 변경 필요성을 제안하는 문서.
- **ECN (Engineering Change Notice)**: 설계 변경 통지서. 승인된 변경 내용을 공식 통지하는 문서.
- **Rev. (Revision)**: 도면 또는 문서의 개정 번호.
- **Cut-in 시점**: 변경 사항이 양산에 적용되는 시점.
- **4M 변경**: Man(작업자), Machine(설비), Material(자재), Method(공법) 변경.

## 4. 절차 (단계별)

### 단계 1: ECR 발의
- **발의자**: 연구소, 품질팀, 생산기술팀, 영업팀(고객 요청 대리) 누구나 가능
- **방법**: ERP 품질/설계 모듈에서 ECR 양식 작성
- **기재 내용**:
  - 변경 대상 부품 (품번, 품명)
  - 변경 사유 (품질 개선, 원가 절감, 고객 요청, 법규 대응 등)
  - 변경 내용 상세 (Before/After 비교)
  - 예상 영향도 (품질, 원가, 납기, 금형, 설비)
  - 긴급 여부 (긴급/일반)

### 단계 2: ECR 검토
- **검토 주관**: 연구소 설계팀
- **참여 부서**: 품질팀, 생산기술팀, 구매팀, 영업팀
- **검토 내용**:
  - 기술적 타당성 검토
  - 품질 영향 평가 (DFMEA/PFMEA 변경 필요 여부)
  - 원가 영향 분석 (금형비, 자재비, 설비 투자 등)
  - 납기 영향 검토 (고객 납품 일정에 차질 여부)
  - 시험/검증 필요 항목 도출
- **기한**: 일반 ECR 접수 후 5영업일 이내, 긴급 ECR 2영업일 이내

### 단계 3: ECR 승인
- **승인권자**: 변경 영향도에 따라 구분
  - 경미한 변경 (치수 공차 내 조정 등): 연구소장 승인
  - 주요 변경 (재질 변경, 형상 변경 등): 연구소장 + 품질임원 승인
  - 고객 관련 변경: 고객 사전 승인 필수 (SQ 포털 통보)
- 승인 시 ECR → ECN 전환

### 단계 4: ECN 발행
- **담당**: 연구소 설계팀
- **ECN 문서 포함 내용**:
  - ECN 번호 (자동 채번: ECN-YYYY-NNNN)
  - 변경 전/후 도면 (Rev. 업데이트)
  - 변경 적용 부품 목록 (BOM 변경 사항)
  - Cut-in 시점 (양산 적용 일자 또는 Lot 번호)
  - 잔여 재고 처리 방안 (폐기, 소진 사용, 재작업)
  - 관련 문서 개정 목록 (Control Plan, 작업 표준서, 검사 기준서 등)
- ERP에 ECN 등록 및 관련 부서 자동 통보

### 단계 5: 변경 준비 및 실행
- **생산기술팀**: 금형 수정, 설비 세팅 변경, 치공구 제작/수정
- **구매팀**: 변경 자재 발주, 기존 자재 재고 확인
- **품질팀**: 검사 기준서 개정, 초물 검사 기준 수립
- **생산팀**: 작업 표준서 개정, 작업자 교육 실시

### 단계 6: 초물 검사 및 검증
- 변경 적용 후 첫 생산품에 대해 초물 검사 실시
- 치수, 외관, 성능 전항목 검사
- 필요 시 고객 승인(PPAP 재진행)

### 단계 7: 양산 적용 및 이력 관리
- MES에 변경 적용 시점(Cut-in) 기록
- ERP BOM 업데이트
- 변경 전/후 재고 구분 관리 (식별 표시)
- ECN 이력 ERP에서 영구 보관

## 5. 관련 시스템
- **ERP 설계/품질 모듈**: ECR/ECN 등록, 승인 워크플로우, BOM 관리
- **SQ 포털**: 고객 관련 변경 사전 통보 및 승인
- **MES**: Cut-in 시점 기록, 생산 이력 추적
- **PLM (제품 수명주기 관리)**: 도면 Rev. 관리, 문서 이력

## 6. FAQ
**Q1. 고객 요청 ECN과 사내 자체 ECN의 처리가 다른가요?**
A1. 기본 프로세스는 동일하나, 고객 요청 ECN은 SQ 포털을 통해 접수되며 고객 지정 기한 내에 적용해야 합니다. 자체 ECN은 고객에게 사전 통보 후 승인을 받아야 양산 적용이 가능합니다.

**Q2. ECN 적용 후 PPAP을 반드시 다시 해야 하나요?**
A2. 변경 범위에 따라 다릅니다. 특별 특성(SC/CC) 관련 변경이면 PPAP 재진행이 필수이며, 경미한 변경은 고객과 협의하여 결정합니다.

**Q3. 긴급 ECN의 경우 절차를 생략할 수 있나요?**
A3. 절차 생략은 불가하나, 검토/승인 기한을 단축(2영업일 이내)하고 병행 처리가 가능합니다. 사후에 반드시 정식 문서화를 완료해야 합니다.
