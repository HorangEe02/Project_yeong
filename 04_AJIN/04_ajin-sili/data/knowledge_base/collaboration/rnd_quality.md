# 연구소 ↔ 품질팀 협업 가이드

## 1. 협업 발생 상황

연구소(R&D)와 품질관리팀의 협업은 제품 개발 초기 단계부터 양산 이후까지 전 수명주기에 걸쳐 발생합니다. 주요 상황은 다음과 같습니다:

### 상황 1: PPAP 진행
신규 부품(AJ-EMP-W100 EMP 워터펌프, AJ-CCH-H200 CCH 공조장치, AJ-OBC-C300 OBC 충전기, AJ-CWH-400 냉각수 히터 등)의 PPAP 진행 시, 연구소는 설계 관련 서류(DFMEA, 도면, 재료/성능 시험)를 작성하고 품질팀은 공정 관련 서류(PFMEA, Control Plan, SPC)를 작성하여 통합 제출합니다.

### 상황 2: ECR/ECN 처리
설계 변경이 필요할 때 ECR 발의 → 검토 → ECN 발행 과정에서 연구소가 기술적 변경을 주도하고, 품질팀이 품질 영향 평가 및 고객 통보를 담당합니다.

### 상황 3: 신규 부품 개발
신규 차종 프로젝트에서 부품 개발 시, 연구소의 설계와 품질팀의 품질 기획(APQP)이 동시에 진행되며, 설계 단계부터 양산 품질을 고려한 협업이 필수적입니다.

### 상황 4: 시장/고객 클레임 중 설계 관련 이슈
고객 클레임의 원인이 설계(재질, 형상, 기능)에 있는 경우 연구소가 원인 분석 및 설계 변경 대책을 주도합니다.

## 2. 각 부서 역할

### PPAP 진행 시 역할 분담
| PPAP 서류 | 연구소 역할 | 품질팀 역할 |
|-----------|------------|------------|
| 설계 도면 | 최신 Rev. 도면 제공 | 도면 Rev. 일치 여부 확인 |
| DFMEA | 작성 주관 | 검토 참여 (공정 관점 의견 제시) |
| PFMEA | 검토 참여 (설계 관점 의견 제시) | 작성 주관 (생산기술팀과 공동) |
| Control Plan | 특별 특성(SC/CC) 지정 | 작성 주관, 검사 방법/빈도 결정 |
| 재료/성능 시험 | 시험 주관, 외부 시험 의뢰 | 시험 결과 검토 및 취합 |
| MSA | - | 측정 시스템 분석 실시 |
| SPC (초기 공정 능력) | - | 초기 공정 능력 분석 실시 |
| PSW | 설계 관련 항목 확인 서명 | PSW 작성 및 최종 제출 |

### ECR/ECN 처리 시 역할 분담
| 단계 | 연구소 역할 | 품질팀 역할 |
|------|------------|------------|
| ECR 발의 | 기술적 변경 필요성 검토, ECR 작성 | 품질 관점 변경 필요성 제기 (또는 검토 참여) |
| 영향도 평가 | 설계 영향 분석, 시험 필요 항목 도출 | 품질 영향 평가 (PFMEA, Control Plan 변경 필요 여부) |
| 고객 협의 | 기술 자료 제공 (도면, 시험 계획) | SQ 포털 통보, 고객 승인 절차 진행 |
| ECN 발행 | ECN 문서 발행, 도면 Rev. 업데이트 | ECN에 따른 검사 기준서 개정 |
| 양산 적용 검증 | 시작품 시험 (재료, 성능) | 양산 초물검사, SPC 분석, PPAP 재진행(필요 시) |

### 신규 부품 개발 시 역할 분담 (APQP 단계별)
| APQP 단계 | 연구소 역할 | 품질팀 역할 |
|-----------|------------|------------|
| 1단계: 기획 | 고객 요구사항 기술 분석 | 품질 목표 설정, 과거 유사 부품 품질 이력 제공 |
| 2단계: 설계/개발 | 제품 설계, DFMEA 작성, 시작품 제작 | 설계 검토 참여, 특별 특성 협의 |
| 3단계: 공정 설계/개발 | 공정 설계 검토 참여 | PFMEA, Control Plan 작성 (생산기술팀과 공동) |
| 4단계: 양산 검증 | 양산 시험 주관 | PPAP 서류 취합/제출, 초기 공정 능력 분석 |
| 5단계: 양산 및 피드백 | 양산 초기 설계 이슈 대응 | 양산 품질 모니터링, 고객 피드백 공유 |

## 3. 정보 전달 체크리스트

### 연구소 → 품질팀 전달 시 필수 정보
- [ ] 최신 도면 (Rev. 및 발행일 명기)
- [ ] DFMEA (최신 Rev.)
- [ ] 특별 특성(SC/CC) 목록 및 지정 근거
- [ ] 재료/성능 시험 성적서 (공인 시험소 성적 포함)
- [ ] ECN 발행 문서 (변경 전/후 비교, Cut-in 시점)
- [ ] BOM 변경 내역 (해당 시)
- [ ] 고객 요구사항 변경 사항 (기술 사양 변경 등)

### 품질팀 → 연구소 전달 시 필수 정보
- [ ] 양산 공정 품질 데이터 (SPC, 불량률 추이)
- [ ] 고객 클레임 내용 (설계 관련 의심 시)
- [ ] PPAP 고객 피드백 (보완 요청 사항)
- [ ] 공정 능력 분석 결과 (Cpk 미달 항목)
- [ ] 수입 검사 부적합 이력 (재질/규격 관련)
- [ ] 고객 심사 지적 사항 중 설계 관련 항목

## 4. 주의사항

1. **도면 Rev. 관리 철저**: 연구소에서 도면을 개정할 때 품질팀에 즉시 통보해야 합니다. 구 Rev. 도면 기반으로 검사 기준서가 운영되면 품질 사고로 이어질 수 있습니다. PLM 시스템에서 도면 변경 알림을 품질팀에 자동 발송하도록 설정합니다.

2. **특별 특성(SC/CC) 지정은 공동 작업**: 연구소가 설계 관점에서 SC/CC를 지정하되, 품질팀이 공정 관점에서 관리 가능 여부를 검토합니다. 공정에서 관리 불가능한 특성이 지정되면 양산에서 지속적 부적합이 발생할 수 있습니다.

3. **시험 일정과 PPAP 일정 연동**: 재료/성능 시험은 외부 공인 시험소에 의뢰하는 경우 2~4주가 소요됩니다. PPAP 제출 기한(양산 SOP 8주 전)을 역산하여 시험 일정을 사전에 확정합니다.

4. **ECN 양산 적용 시 잔여 재고 처리 합의**: ECN 적용 시 변경 전 제품 잔여 재고를 어떻게 처리할지(소진 사용, 재작업, 폐기) 연구소와 품질팀이 사전에 합의해야 합니다. 고객 승인이 필요한 경우 SQ 포털을 통해 통보합니다.

5. **설계 변경 시 PFMEA/Control Plan 연쇄 업데이트**: 연구소의 설계 변경(ECN)은 품질팀의 PFMEA, Control Plan, 검사 기준서 개정을 연쇄적으로 유발합니다. ECN 발행 시 품질팀의 문서 업데이트 완료 일정을 함께 확인합니다.

6. **클레임 원인이 설계인 경우 민감하게 대응**: "설계 불량"이라는 결론은 고객에게도 민감한 사안입니다. 연구소와 품질팀이 충분히 협의하여 정확한 원인과 대책을 수립한 후 고객에게 회신합니다. 설계 변경이 필요한 경우 ECN 절차를 신속히 진행합니다.
