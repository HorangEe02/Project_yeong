# 품질팀 ↔ 생산기술팀 협업 가이드

## 1. 협업 발생 상황

품질관리팀과 생산기술팀은 제조 현장에서 가장 빈번하게 협업하는 부서입니다. 주요 협업 상황은 다음과 같습니다:

### 상황 1: 공정 불량 발생 및 대응
프레스 공정(AJ-AP-001 A-Panel, AJ-BP-002 B-Pillar)에서 크랙, 주름, 치수 이탈 등 불량이 발생하거나, 용접 공정에서 너깃 미형성, 스패터 과다 등 불량이 발생했을 때 공동으로 원인을 분석하고 대책을 수립합니다.

### 상황 2: 4M 변경 관리
설비 교체/수리, 금형 수정, 자재 변경(대체재), 공법 변경 등 4M 변경이 발생할 때, 생산기술팀이 변경을 실행하고 품질팀이 변경 후 품질 검증 및 고객 통보 여부를 판단합니다.

### 상황 3: 설비 관련 품질 이슈
용접 모니터링 시스템에서 이상 알람이 발생하거나, 프레스 설비 조건(BHF, SPM)이 이탈했을 때 품질 영향도를 공동으로 평가합니다.

### 상황 4: 신규 부품 양산 준비
신규 부품(예: AJ-CWH-400 냉각수 히터) 양산 준비 시 공정 흐름도, PFMEA, Control Plan을 공동으로 작성하고, 초기 공정 능력(SPC)을 검증합니다.

### 상황 5: 고객 클레임 대응
고객 클레임 8D 분석 시 공정 관련 원인 분석을 생산기술팀이 지원하고, 영구 대책(금형 수정, 설비 조건 변경 등)을 생산기술팀이 실행합니다.

## 2. 각 부서 역할

### 공정 불량 대응 시 역할 분담
| 단계 | 품질팀 역할 | 생산기술팀 역할 |
|------|------------|----------------|
| 불량 감지 | 순회 검사/자주 검사에서 불량 발견 → 라인 정지 판단 | 안돈 알람 확인 및 현장 출동 |
| 초기 조치 | 부적합품 격리, 불량 현황 기록 | 설비/금형 상태 긴급 점검, 응급 조치 |
| 원인 분석 | 불량 현상 분류, SPC 데이터 분석, MES 이력 확인 | 설비 조건(전류, 압력, 온도) 확인, 금형 상태 점검 |
| 대책 수립 | 검사 강화 방안, Control Plan 업데이트 | 설비/금형 수리/조정, 공정 조건 최적화 |
| 검증 | 대책 적용 후 초물검사, SPC 재분석 | 대책 실행 및 안정화 확인 |
| 문서화 | 부적합 보고서, PFMEA 업데이트 | 작업 표준서 개정, 설비 이력 기록 |

### 4M 변경 관리 시 역할 분담
| 단계 | 품질팀 역할 | 생산기술팀 역할 |
|------|------------|----------------|
| 변경 발의 | - | 변경 필요성 검토 및 ECR 발의 (또는 변경 요청서 작성) |
| 영향도 평가 | 품질 영향 평가 (PFMEA 재분석) | 기술적 영향 평가 (공정 조건, 생산성) |
| 고객 통보 판단 | 고객 통보 필요 여부 결정, SQ 포털 통보 | 기술 자료 제공 (변경 전/후 비교) |
| 변경 실행 | - | 설비 조정, 금형 수정, 자재 교체 등 실행 |
| 변경 후 검증 | 초물검사 실시, SPC 분석, PPAP 재진행(필요 시) | 공정 안정성 확인, 생산성 확인 |
| 이력 관리 | ERP 4M 변경 이력 등록, Control Plan 업데이트 | MES 변경 이력 기록, 작업 표준서 개정 |

## 3. 정보 전달 체크리스트

### 품질팀 → 생산기술팀 전달 시 필수 정보
- [ ] 불량 현상 상세 (사진 포함)
- [ ] 불량 발생 공정 및 설비 번호
- [ ] 불량 발생 시간대 및 수량
- [ ] 해당 Lot의 MES 생산 이력 (작업자, 자재 Lot, 설비 조건)
- [ ] SPC 이탈 데이터 (해당 시)
- [ ] 고객 클레임 여부 및 회신 기한 (해당 시)
- [ ] 과거 유사 불량 이력 (ERP 검색 결과)

### 생산기술팀 → 품질팀 전달 시 필수 정보
- [ ] 4M 변경 내용 상세 (Before/After)
- [ ] 변경 사유 및 기술적 근거
- [ ] 변경 적용 예정일 (Cut-in 시점)
- [ ] 설비/금형 수리/조정 완료 보고
- [ ] 공정 조건 변경 내역 (수치 포함)
- [ ] 변경 후 초물검사 결과
- [ ] 잔여 재고(변경 전 제품) 처리 방안

## 4. 주의사항

1. **공정 조건 무단 변경 절대 금지**: 생산기술팀이든 현장 작업자든, 용접 전류, 프레스 BHF 등 공정 조건을 품질팀 승인 없이 변경하면 안 됩니다. 이는 4M 변경에 해당하며, 고객 통보 누락 시 중대 품질 사고로 확대될 수 있습니다.

2. **불량 발생 시 현물 보존**: 품질팀이 분석하기 전에 불량 현물을 폐기하거나 재작업하면 원인 분석이 불가능해집니다. 반드시 불량 현물을 격리 보관하고 품질팀 확인 후 처리합니다.

3. **PFMEA는 공동 문서**: PFMEA는 품질팀과 생산기술팀이 함께 작성/유지하는 문서입니다. 한쪽에서 단독으로 수정하지 말고, 변경 시 반드시 양팀 검토 후 업데이트합니다.

4. **일일 조회 참석**: 품질팀과 생산기술팀 담당자는 매일 아침 생산 조회에 함께 참석하여 전일 품질 이슈, 당일 생산 계획, 설비/금형 상태를 공유합니다.

5. **긴급 대응 시 역할 혼선 방지**: 라인 정지급 불량 발생 시 누가 무엇을 하는지 사전에 명확히 정해두어야 합니다. 품질팀은 불량 판정 및 격리, 생산기술팀은 설비/금형 점검 및 조치에 집중합니다.

6. **설비 PM 일정과 검사 일정 연동**: 설비 예방 보전(PM) 후에는 반드시 초물검사를 실시하여 공정 조건이 정상인지 확인합니다. PM 일정을 품질팀과 사전 공유하여 검사 인력을 배치합니다.
