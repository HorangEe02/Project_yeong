# 설계변경통보서 (ECN)

| 항목 | 내용 |
|------|------|
| **문서번호** | ECN-2026-001 |
| **발행일** | 2026-01-20 |
| **대상부품** | OBC 충전장치 (On-Board Charger) 방열 모듈 |
| **품번** | AJ-OBC-HS-4012 |

## 1. 변경 내용

| 구분 | 변경 전 | 변경 후 |
|------|---------|---------|
| 방열판 면적 | 85cm² | 119cm² (40% 확대) |
| 방열판 핀 구조 | 직선형 핀 (Straight Fin) | 오프셋 핀 (Offset Strip Fin) |
| 핀 높이 | 8mm | 10mm |
| 서멀 패드 | 미적용 | 서멀 패드 적용 (열전도율 5.0 W/mK, 두께 1.5mm) |
| 서멀 패드 적용 위치 | - | MOSFET ↔ 방열판 계면, 트랜스포머 ↔ 하우징 계면 |
| 방열판 소재 | AL6063-T5 | AL6063-T5 (동일) |
| 열저항 (Junction to Case) | 1.8°C/W | 1.1°C/W (목표) |

---

## 2. 변경 사유

- 2025년 하반기 NE1 차종 OBC 과열 관련 필드 클레임 3건 발생
  - CLM-2025-OBC-007: 급속충전 반복 시 OBC 온도 과승 경고등 점등
  - CLM-2025-OBC-008: 하계 외기온 38°C 이상 환경에서 충전 출력 디레이팅 조기 발생
  - CLM-2025-OBC-011: OBC 내부 MOSFET 열화 의심 (충전 효율 저하)
- 근본 원인 분석 결과, 방열판 면적 부족 및 MOSFET-방열판 간 열접촉 저항 과다로 확인
- 서멀 패드 미적용으로 인한 공기층(Air Gap) 존재가 열전달 효율 저하의 주요 원인
- 급속충전(350V/11kW) 반복 사이클에서 정션 온도 150°C 초과 확인 (허용: 135°C)
