# 설계변경통보서 (ECN)

| 항목 | 내용 |
|------|------|
| **문서번호** | ECN-2025-001 |
| **발행일** | 2025-10-25 |
| **대상부품** | EMP 워터펌프 (Electric Motor Pump Water Pump) |
| **품번** | AJ-EMP-WP-1024 |
| **변경유형** | 소재 변경 |
| **적용차종** | NE1 (아이오닉5 후속) |
| **변경요청출처** | 8D-2025-001 시정조치 보고서 |

---

## 1. 변경 내용

| 구분 | 변경 전 | 변경 후 |
|------|---------|---------|
| 실링 소재 | NBR (니트릴 부타디엔 고무) | EPDM (에틸렌 프로필렌 디엔 모노머) |
| 경도 (Shore A) | 70±5 | 65±5 |
| 내열 온도 | -30°C ~ +120°C | -40°C ~ +150°C |
| 내냉각수성 | 일반 (LLC 기반) | 강화 (EV 전용 냉각수 대응) |
| 실링 단면 형상 | O-Ring 단순 원형 | O-Ring 원형 (동일) |

---

## 2. 변경 사유

- 8D-2025-001 시정조치 결과, 기존 NBR 실링재가 EV 전용 냉각수(글리콜 기반) 환경에서 6개월 이상 사용 시 팽윤 및 경화 현상 발생 확인
- 필드 클레임 3건 접수 (냉각수 누수로 인한 펌프 성능 저하)
- EPDM 소재는 EV 냉각수 내화학성 우수하며, 고온 내구성이 NBR 대비 30°C 이상 향상
- 현대차 품질본부 긴급 품질 개선 요청 (QR-HMC-2025-0892)

---

## 3. 영향 범위

| 영향 항목 | 상세 내용 | 영향도 |
|-----------|-----------|--------|
| **공정** | 실링 조립 공정 변경 없음 (치수 동일) | 낮음 |
| **금형** | 실링 사출 금형 변경 없음 | 없음 |
| **검사 기준** | 수입검사 기준서 개정 필요 (소재 성적서 항목 추가) | 중간 |
| **BOM** | 자재 코드 변경 (AJ-SL-NBR-022 → AJ-SL-EPDM-022) | 중간 |
| **협력사** | 실링 공급사 변경 검토 (기존: 성우하이텍 → 신규: 평화오일씰) | 높음 |
| **시험 성적** | EPDM 소재 내냉각수 침지 시험 1,000시간 완료 필요 | 높음 |
