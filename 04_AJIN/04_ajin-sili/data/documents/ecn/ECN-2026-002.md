# 설계변경통보서 (ECN)

| 항목 | 내용 |
|------|------|
| **문서번호** | ECN-2026-002 |
| **발행일** | 2026-02-15 |
| **대상부품** | B-Pillar (센터필러 보강재) |
| **품번** | AJ-BP-BPR-5023 |
| **변경유형** | 소재 변경 (핫스탬핑 초고강도강) |
| **적용차종** | SU2 (투싼 후속) |
| **변경요청출처** | 현대차 차체설계팀 설변 요청 - HMC-EC-2026-0215 |

---

## 1. 변경 내용

| 구분 | 변경 전 | 변경 후 |
|------|---------|---------|
| 소재 | 22MnB5 (Al-Si 코팅) | Usibor 2000 (Al-Si 코팅) |
| 인장강도 (핫스탬핑 후) | 1,500 MPa | 2,000 MPa |
| 항복강도 | 1,100 MPa | 1,400 MPa |
| 연신율 | 6% | 5% |
| 판두께 | 1.8mm | 1.5mm (경량화) |
| 부품 중량 | 2.4kg | 2.0kg (-17%) |
| 코팅 타입 | AS150 (Al-Si) | AS150 (Al-Si) 동일 |

---

## 2. 변경 사유

- 현대차 SU2 차종 Euro NCAP 2026 신규 평가 프로토콜 대응 필요
  - 측면 충돌(Side Pole Impact) 기준 강화에 따른 B-Pillar 강성 향상 요구
- Usibor 2000 적용 시 인장강도 33% 향상으로 측면 침입량 15mm 감소 (CAE 해석 결과)
- 동시에 판두께 0.3mm 저감으로 부품 중량 17% 경량화 달성 (차량당 0.8kg 절감)
- 현대차 2026년 차체 경량화 로드맵에 따른 초고강도 소재 전환 방침 적용
- ArcelorMittal Usibor 2000 소재 양산 공급 체계 확립 완료 (2025년 Q4)

---

## 3. 영향 범위

| 영향 항목 | 상세 내용 | 영향도 |
|-----------|-----------|--------|
| **공정** | 핫스탬핑 공정 조건 전면 재설정 (가열 온도, 유지 시간, 냉각 속도) | 높음 |
| **금형** | 핫스탬핑 금형 냉각채널 재설계 (냉각 속도 30°C/s → 35°C/s 이상) | 높음 |
| **검사 기준** | 인장시험 기준 변경, 미세조직 검사(마르텐사이트 분율) 기준 신설 | 높음 |
| **BOM** | 소재 코드 변경, 판두께 변경에 따른 중량 정보 갱신 | 중간 |
| **레이저 트리밍** | 소재 강도 증가에 따른 레이저 출력 및 속도 재설정 | 중간 |
| **스폿 용접** | 용접 전류/가압력 조건 재설정 (Usibor 2000 용접성 사전 검증 필요) | 높음 |
| **CAE 해석** | 측면 충돌 CAE 모델 소재 물성치 업데이트 및 재해석 | 중간 |
